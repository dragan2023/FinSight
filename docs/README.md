# FinSight 文档入口

## 1. 当前开发路线

新计划 01–08 的本地功能已完成并按[金融研究功能开发计划](金融研究功能开发计划/00_计划索引.md)验收。阶段 05–08 覆盖公司与同行、理由跟踪、板块/基金/市场复盘、研究资产库/本地导出与离线故障矩阵；不制作发布包，不开放公网服务。新计划持续要求缺数据继续分析、可靠 JSON、用户主动再分析和全部服务自带 Key。

[原金融洞察软件开发计划](金融洞察软件开发计划/00_计划索引.md)仅保留历史：原 01 是基础设施实现记录，原未执行的 02–07 已由新计划取代，不再作为功能开发指令。

## 3. 当前完成范围

已完成原计划阶段 01 的应用基础及新计划 01–08 的本地研究闭环。运行方法见[项目 README](../README.md)，可操作的流程和验收命令见[功能使用与验证说明](功能使用与验证说明.md)。不要把尚未真实验证的外部能力当成已验证功能。

同花顺和单条 AI 研究任务已有小范围实测记录；搜索、Tushare 等能力仍需用户使用自己的 Key 主动授权后逐项验证。首页、设置页及已保存内容可在无 Key 情况下使用；一键 BAT 的安全重启、健康检查与默认浏览器打开流程保持不变。

新增三家官方客户端与前端能力配置，默认使用 DeepSeek Vision Exp、GLM-5.3 Flash、Qwen3.8 Flash。来源、参数和范围见[模型服务商接入说明](模型服务商接入说明.md)。首次保存可在页面安全初始化存储；手动模型调用无需修改环境开关。
