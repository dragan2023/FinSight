## 0. 一句话结论

**没有任何比较过预注册门槛（|t| ≥ 3.603），因此不得称为发现。**

| 字段 | 口径 | `base_all`（主检验） | 最大 \|t\|（含全部变体） | 门槛 |
|---|---|---|---|---|
| `f_score` | **`next_open`（可成交）** | **−0.0014（t=−0.10）** | 1.12（连板内） | 3.603 |
| `f_score` | `close_t`（对照） | −0.0061（t=−0.41） | 0.98 | 3.603 |
| `f_score_ratio` | **`next_open`** | **+0.0319（t=+1.83）** | **1.97**（加严匹配） | 3.603 |
| `f_score_ratio` | `close_t` | +0.0333（t=+1.77） | 1.91 | 3.603 |

- 样本：**732 个可用评估日 / 2,741 个事件**（2022-01 → 2026-09，186 只高流动性标的的涨停）；
- **`f_score_ratio` 是唯一"疑似为正"的东西**：两种口径、两个时段**符号一致为正**（+1.8pp ~ +5.4pp），
  最大 |t| = **1.97**——刚过逐检验的 1.96，**离族级门槛 3.603 差得很远**；
- 它的同源兄弟 `f_score`（原始分值）**分时段符号翻转**（2022–2024 −3.4%，t=−1.72；2025–2026 +1.8%，t=+0.92）
  → 不支持"财务质量稳定地调节涨停后续表现"。

> 确认必须靠**新数据**（见 §7 的 D67）。

## 1. 第 0 步：这个假设有没有样本（**先测再做**）

财务数据集只覆盖 202 只（按 2026-09-04 成交额前 200 + 已确认标的选出），而涨停池覆盖 4,849 只。
交集规模直接决定假设能不能做，所以**先量，再登记**：

| 项 | 实测值 |
|---|---|
| 202 只财务标的中出现在涨停池的 | **186 只** |
| 这些标的的涨停事件 | **2,846 条**，落在 **749 个交易日** |
| 事件当日能取到 PIT F-Score 的 | **2,846 条（100%）**，0 缺失 |
| F-Score 分布 | 0–7 全覆盖，均值 **4.014**、中位 **4.0**（分组有意义） |
| 同日有 ≥2 只**不同**标的的交易日 | **513**（可做同日高低对比的下限） |

**结论**：样本够（比预想的大得多）——高流动性大票也会涨停，且它们的财报数据齐全，
所以"按评估日聚合的配对超额"这一步站得住。

## 2. 预注册（门槛 3.603 是**怎么来的**）

登记条目：`limit_up_financial_interaction_design@v1` + 两条因子
（`limit_up_financial:f_score@v1`、`limit_up_financial:f_score_ratio@v1`），
全部写在**看到任何结果之前**（`scripts/governance_register_financial_interaction.py`）。

**计数口径**（与机器自己的实现一致）：每 (字段, 口径) = 4 变体 × 3 统计量 + 8 分时段复现 = **20 条**；
本轮 2 字段 × 2 口径 = **80 条**。

| 读法 | 计数 | 门槛 |
|---|---|---|
| 新族读法（交互族先验 0） | 80 | \|t\| ≥ 3.4205 |
| **保守读法（把两个母族已看过的 43 + 36 = 79 条也计入）** | **159** | **\|t\| ≥ 3.6031** |

**本报告采用保守读法**（D55：族级计数只能算严、不能算松）。交互假设是站在两个母族
已经看过的比较之上"再问一次"，把它们计入不会冤枉自己；漏计却会把门槛算松。

设计要点（全部先于结果写死）：分组用**当日池内中位数**；对照是同日同成交额十分位的非涨停标的
（`matched_*` 再加事前 40 日动量三分位）；**主检验用可成交口径 `next_open`**（D53）；
4 个变体（all / first_board / multi_board / matched_all）；分时段 2022–2024 与 2025 起；
安慰剂只作机制自检。

## 4. 判读

### 4.1 未过门槛 = 不得称为发现

最大 |t| = **1.97**（`f_score_ratio` `matched_all`）对门槛 **3.603**。
按本项目从 `13` 号文档起就执行的纪律：**没过门槛就是没过门槛**，不得表述为"财务质量能调节
涨停后的表现"，也不得通过换分组、换窗口、换终点去"修"它。

### 4.2 为什么"疑似为正"仍然站不住

`f_score_ratio` 看起来最像信号（两口径 + 两时段同号为正），但四条理由否掉了它：

1. **同源**：它是 `f_score` 的归一化版本（同一批判定），**不是独立证据**；
   而原始分值 `f_score` 分时段**符号翻转**——若财务质量真是稳定的调节变量，两者不该背离；
2. **两者并非总是同一套分组**：全样本下 `f_score` 与 `f_score_ratio` 的高组超额不同
   （+5.45% vs +7.72%）——因为"可算项数"在池内并不一致（银行没有营业成本 → 6/7 项），
   归一化确实改变了分组；这也说明**不能用"反正一样"来省掉其中一条**（它与 2025 段
   恰好完全一致，那是该段内可算项数统一所致）；
3. **|t| ≈ 1.97 只是刚过逐检验 1.96**，而这一轮我们看了 **159 条**比较；
4. **样本选择偏置**（§5）：只在"高流动性大票的涨停"上检验过。

### 4.3 登记为待确认候选（沿用 `16` 号文档 F45 的处置方式）

`f_score_ratio` 的正号**不足以成为结论**，但也**不值得直接丢掉**，因此登记为**待确认候选**：

- **不得**在同一份数据上换窗口/换分组/换终点重复跑（A.1/A.2）；
- 要确认，只能靠**新数据**：把财务覆盖从 202 只放宽到全市场（D36 的范围放宽），
  在**样本外**（更宽的股票池 / 更长的区间）用**新 reference** 重新预注册后检验。

## 5. 样本选择偏置（结构性，必须一并阅读）

财务数据集只覆盖 **202 只**（按 2026-09-04 成交额前 200 + 已确认标的选出），因此本交互只在
**高流动性大票的涨停事件**上被检验过。`23` §5 已量化：这些标的在**当日全市场**成交额分位的
**中位数 0.8903、第 10 百分位 0.8453、最小 0.801**（从未掉出全市场前 20%）。

**小票涨停占了涨停池的大多数，但不在样本内。** 结论只能表述为
「在这 186 只高流动性标的的涨停事件上未过门槛」，**不得**外推到小票涨停或全市场。

## 6. 本轮实现：外部字段机制（**没有第二套估计量**）

要做"池内字段之外的变量"当分组变量，有两条路：另写一套评价，或**把外部数据做成字段**。
本项目一贯的纪律是后者（`13`/`17` 号文档反复强调"估计量只能有一份"），因此：

- `events.py` 新增 **`EXTERNAL_FIELDS`**（`f_score` / `f_score_ratio`）与 `KNOWN_FIELDS`；
  字段的取值由注入的 **provider** 提供：`provider(field, thscode, date_ms) -> float | None`；
- 分组、对照匹配（成交额十分位 × 事前动量三分位）、池内分层、重抽、多重检验计数
  **全部复用事件研究原有的代码路径**——本轮只增加了"取值从哪来"这一个接点；
- `ALL_FIELDS` **刻意不含**外部字段：`--field all` 仍只跑池内字段，
  避免在没有 provider 时产出"看着有结果"的空报告（有测试钉住这条）；
- 每个**已知**字段（含外部字段）都必须声明所属统计族（守卫测试已升级为更强的不变量）；
- provider 按 **(标的, 日期)** 缓存整份快照：事件研究对每个评估日会为池内全部标的取值，
  按字段缓存会让快照被重算好几遍（本轮实测缓存 61,352 个 (标的, 日期)，全样本 70 秒跑完）。

| # | 决策 | 理由 |

| **D67** | 「财务质量 × 涨停事件」**未过门槛，不得称为发现**；`f_score_ratio` 的双口径/双时段一致正号只登记为**待确认候选**，确认必须用**新数据**（放宽财务覆盖到全市场或样本外）＋**新 reference**；**禁止**在同一份数据上换窗口/换分组重复跑 | §3/§4：最大 \|t\| = 1.97 对门槛 3.603；同源兄弟 `f_score` 分时段符号翻转；样本选择偏置未消除 |

## 8. 限制与仍未解释（诚实挂着）

1. **样本选择偏置**（§5）：结构性，不可由统计消除。
2. **功效**：732 个评估日、2,741 个事件，但每天只有约 **3.7** 个合格事件（同日同池对比的结构
   决定了有效自由度远小于事件数）。以本样本的离散度，**1.5–2.5% 量级的效应测不稳**——
   "未过门槛"不等于"没有效应"，只是**没测出来**。
3. **财务覆盖只到 2016-Q4 / 涨停池只到 2022-01**，实际区间由涨停池决定。
4. **未计交易成本**，且 `next_open` 口径仍假设"次日开盘可成交"（`21` §6 第 2 条的限制同样适用）。
5. **`f_score` 与 `f_score_ratio` 背离的原因未深究**（是"可算项数不一致"所致这一点可由
   2025 段的完全一致反推，但**没有逐日核对**到每一只标的上）。
