# 涨停池事件研究：封成比（无量纲口径）—— 市值混淆被削弱

> 承接 `16` 号文档 §4.1 与决策 **D44**，以及 §10 第 1 项。
> 那里发现：`seal_money` 是**绝对金额**、与市值正相关，而 v3 的三个变体都没匹配市值
> → "封单额效应"里**不能排除规模（size）**。
> 本文档记录排混淆的那一轮：把封单额换成**无量纲**的封成比再验一遍。
> **结论：效应不仅存在，而且比绝对值口径更强**——"绝对金额只是市值的影子"这一解释被削弱。

---

## 1. 一句话结论

| 口径 | 高−低 | t 值 | 族级门槛（40 次比较） | 判定 |
|---|---|---|---|---|
| 绝对封单额 `seal_money`（`16`） | +1.93% | +8.23 | 3.227 | 成立，但混着未匹配的市值 |
| **封成比 `seal_ratio`（本文）** | **+2.48%** | **+10.47** | 3.227 | **成立**，且**强于**绝对值口径 |

**封成比 = 封单额 ÷ 当日成交额**（无量纲）。它把"封单有多厚"与"当天有多没人卖"合在一起，
**不含绝对规模**。换口径后效应没有消失、反而更大且更稳（四个变体全部越过族级门槛 3.227），
说明原先的封单额结论**不是**绝对金额/市值的影子。

**但仍不能升级为"封单强度是原因"**，两条理由（§5）：两轮口径**共用同一底层数据**
（高度相关，不是独立复现）；本地**仍没有流通市值**数据，市值混淆是被削弱而非消除。

## 3. 定义与实现

**公式**：`seal_ratio = seal_money ÷ turnover_today`（当日成交额）。

选这个分母的理由：封单额以**元**为单位，大市值/高价股天然更大；除以当日成交额后该比值
**无量纲**，既不含绝对规模，又顺带刻画了"封板日成交被压缩、没人卖"这一层。

实现上新增**派生字段**机制（`backend/app/screener/events.py` 的 `DERIVED_FIELDS`）：
取值由「涨停池条目 × 当日横截面」算出，而不是池子接口直接给。定义只写一处，
评估侧与登记侧引用同一份说明；`ALL_FIELDS = 原生字段 + 派生字段`，
分层/匹配/重抽全部复用同一条代码路径（所以两个口径的结果可直接并排比较）。

**缺值绝不填补**：当日成交额缺失或 ≤ 0 时**不给值**（既不算高组也不算低组）。
拿 0 或全网均值去凑，会把"缺数据"做成"低封成比"塞进低组——那正是 C2 里
"缺失值不填 0"要防的同一类错误。有测试钉住三种缺法。

## 5. 判读：混淆被削弱到什么程度

**可以说的**：

1. 封单类变量（无论绝对金额还是无量纲比值）与"事件后 20 日相对同层对照的表现"**稳健相关**；
2. **不是绝对规模造成的**：换成无量纲比值后效应**更大**（+2.48% vs +1.93%），
   且同样通过事前动量匹配、池内分层与分时段复现；
3. 再次确认**有信息的是低组**：高封成比组 +0.26%（基本持平），低封成比组 **−2.21%**
   → 封成比区分的是**亏损幅度**，不是收益机会。

**仍然不能说的**：

1. **不能说"封单强度是原因"。** 两轮口径共用**同一底层数据**（`seal_money` 与
   `turnover_today` 都来自涨停池/行情），彼此**高度相关，不构成独立复现**——
   本轮的贡献是**削弱**了规模解释，不是给出第二条独立证据。
2. **市值混淆只被削弱，没有消除。** 封成比排掉的是"成交额口径"的规模；本地仍**没有
   流通股本/市值**数据，无法做真正的市值匹配。大市值股票的封成比分布本身就更靠中低段，
   这个层面的差异无法在现有数据里扣掉。
3. **仍不是可实现收益。** 高封成比那批正是"封板到收盘"的股票，**当日收盘价买不到**；
   窗口从 `close_T` 起算，隐含"按收盘价成交"（D43 / D46 维持）。
4. **未匹配行业、β**；本地库不含退市标的（负向超额被低估）。

## 6. 决策（D47–D48）

| # | 决策 | 理由 |
|---|---|---|
| **D47** | 封单类结论的表述**可以升级一格**：由"高封单标的优于低封单标的"升为"**高封成比标的优于低封成比标的，且该差异不是绝对金额规模造成的**"；**仍不得**表述为"封单强度驱动/承接力是原因" | §5：无量纲口径更强（+2.48% vs +1.93%，均过族级门槛 3.227）→ 规模解释被削弱；但两轮**同源、非独立**，且市值未真正匹配 |
| **D48** | **停止在同一底层数据上继续加变体**。下一步只能做两类事：① 引入**独立数据**（财务/市值/行业）；② 做**可成交性检验**（把结果窗口从 `close_T` 改到 T+1 开盘），两者都必须新开 reference | 继续加同源变体只会把多重检验计数推向 60、80，而信息量不增——这正是 A.2 要防的"用搜索空间换显著性" |
