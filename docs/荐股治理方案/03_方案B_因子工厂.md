# 方案 B · 因子工厂

> **一句话**：把信号来源从 LLM 换成全市场横截面因子，用 IC/IR、走查与多重检验校正来判定
> 有效性；LLM 退出决策路径，只保留解释与风险叙述的职责。
>
> **它回答的问题**：在 A 股全市场上，是否存在一个统计上站得住、且扣除成本后仍有净收益的
> 排序规则？

---

## 1. 定位

方案 B 的核心判断是：**LLM 不可能是 alpha 的来源。**

理由不是"LLM 不够聪明"，而是**不可证伪**：同一个提示词、同一个模型，今天的输出与明天
不同；模型版本会被服务商悄悄替换；`temperature` 之外的采样与路由不可控。
一个无法逐位复现的过程，无法通过科学方法评估。

FinSight 现有的顾问链其实已经承认了这一点——`_enrich_card()` 让 LLM **只能降级不能升级**
（`advisor/graph.py:696-704`），`_recommendation_tier()` 明确写"LLM 的措辞不能改变本函数结果"。
方案 B 只是把这条原则贯彻到底：**既然 LLM 不能决定方向，就让它彻底不参与方向。**

因此方案 B 的产物不是"更好的顾问"，而是一个**每日可复现的全市场排序** + 一套统计判定。

## 2. 可行性依据

| 依据 | 事实 |
|---|---|
| 行情原料充足 | `daily_k` 1026 万行 / 5556 只 / 2427 交易日 / 2016-09-06→2026-09-04 |
| 财务原料可用 | `financial_statements` 131.6 万行 / 5556 只 / 26 字段 / 10 个年报期 |
| **时点信息存在** | 该表含 `disclosed_at_ms`（披露时间戳）→ **可以做 point-in-time 财务，避免用未披露数据** |
| 复权原料存在 | `adjustment_factors` 5.71 万行 / 5420 只，且已有公司行动感知的总收益序列函数 |
| 既有算法可复用，**但有字段缺口** | `advisor/algorithms/f_score.py`（Piotroski F-Score）与 `zscore.py`（Altman Z-Score）公式已实现、年报口径也匹配；但**纯本地数据算不出来**：Z-Score 需的 `retained_earnings` / `market_value_equity` 全仓库无人生产，F-Score 需的 ROA 不在 `financial_statements` 里。详见 01 号文档 P0-3 |
| 组合层回测已写好但未接线 | `portfolio/backtest.py` 的 `run_portfolio_backtest()`，无生产引用、无测试，正好接线 |
| 本地计算不触红线 | 打分全部基于本地 DuckDB → 本地、免费、不联网，与"付费 API 不自动调用"无冲突 |

### 必须先确认的三件事（B1 阶段第一项工作）

1. **财务因子的字段缺口要先决定怎么补**（见 01 号文档 P0-3）。当前 `financial_statements`
   的 26 个字段既没有 ROA 指标，也没有 Z-Score 需要的留存收益与权益市值，所以
   "复用已实现的 F-Score / Z-Score"这个设想**不能直接成立**。二选一：扩展同步范围补齐字段，
   或第一期只用「量价 + 流动性」因子并把限制登记在册。

2. **幸存者偏差程度**。`daily_k` 有 5556 个标的，若其中包含已退市/长期停牌的证券，
   则幸存者偏差较小；若只有当前存续标的，则所有历史统计都会高估收益。验证方式：

   ```sql
   -- 最后一个交易日远早于 2026-09-04 的标的数量 = 疑似退市/长期停牌
   SELECT count(*) FROM (
     SELECT thscode, max(date_ms) AS last_ms
     FROM daily_k GROUP BY thscode
   ) WHERE last_ms < (SELECT max(date_ms) FROM daily_k) - 30*86400000;
   ```

3. **`disclosed_at_ms` 的可用性与一致性**。抽查若干标的，确认该字段真实反映披露时间
   而非回填时间；若不可靠，point-in-time 退化为"按 `period_end_ms` + 固定滞后"。

## 3. 目标与非目标

### 目标

1. 每日输出**全市场横截面排序**（标注为"候选池"，遵守既有红线），并给出每只的因子分解。
2. 建立因子研究流水线：IC/IR 时序、分位组合、换手率、成本敏感性。
3. 建立**走查（walk-forward）**评估：滚动窗口内调参、窗口外评估，禁止全样本调参。
4. 给出可证伪结论：因子组合扣除成本后，净收益的显著性检验结果。

### 非目标

- **不让 LLM 参与方向判断**。LLM 仅用于生成解释文本、列举反证与失效条件。
- 不做日内/高频。数据是日频未复权/前复权日 K。
- 不接券商、不下单、不模拟成交对外宣称。
- 不承诺收益，输出必须是概率与排名，不是点值承诺。

## 4. 架构改动

### 4.1 新增 `backend/app/screener/` — 时点横截面

- `cross_section(date_ms, universe, factors, min_turnover, limit)`：**固定 SQL 模板**，
  参数经枚举校验，**禁止调用方传入任何 SQL 片段或表达式**（沿用
  `market_warehouse/repository.py` 既有约定："no caller-supplied SQL"）。
- 股票池规则显式化：排除 ST、停牌、次日无法正常买入的连续涨停、身份不可确认的证券。
- **复用 `market_warehouse/repository.py:203+` 的 `corporate_action_total_return_history()`**，
  并对 `ex_date_ms` 强制 **as-of 截断**（见 01 号文档 P0-4.3）。

### 4.2 新增 `backend/app/factorlab/` — 因子研究

| 模块 | 职责 |
|---|---|
| `factors/` | 因子定义（量价、财务、估值），每个因子声明：先验逻辑、所需字段、覆盖度、方向、更新频率 |
| `ic.py` | Rank IC 时序、IC 均值/标准差/IR、IC 衰减曲线（1/5/10/20/60 日） |
| `quantile.py` | 分位组合（A 股做多为主：多头组 vs 基准），分组单调性检验 |
| `walkforward.py` | 滚动窗口调参 + 窗口外评估，产出时间序列的样本外净值 |
| `significance.py` | **多重检验校正**：Deflated Sharpe Ratio、对因子数量的 Bonferroni / FDR 控制 |

### 4.3 接线 `backend/app/portfolio/`

`portfolio/backtest.py` 已有 `run_portfolio_backtest()`（含 `excess_vs_cash_pct` 等指标），
目前**既无生产引用也无测试**。因子组合的净值、回撤、换手与成本敏感性直接接它，
而不是另写一套。

### 4.4 顾问链的角色收缩

- `advisor/graph.py` 的职责从"产生方向"改为：
  1. 接收因子排序结果作为**证据**（可复用 `_strategy_pack()` 的编号与引用机制）；
  2. 生成解释、反证、失效条件与观察哨；
  3. 继续用 `advice_ledger` + `research_predictions` 双轨登记，**保留现有审计资产**。
- **不删除** `_enrich_card()` 的降级逻辑与 `_recommendation_tier()` 的档位阶梯——
  它们仍是"LLM 不得抬档"的守卫。
- 标的层的 `strategy_experiments` / `strategy_reviews` 阶梯**保留**，用于单标的复盘；
  组合层评级作为**新增的第二层**，不替换它。

## 5. 治理机制（本方案的重点）

方案 B 的治理是**统计治理**，核心是防止"在 100 个因子里挑出 5 个显著的然后宣称发现规律"。

### 5.1 因子准入（先于任何回测）

一个因子进入研究池前必须满足：

1. **先验逻辑**：能用一句话说明经济/行为学机制，不接受纯数据挖掘产物。
2. **数据可用性**：所需字段覆盖度 ≥ 阈值，且**时点可得**（不得使用未披露数据）。
3. **换手率上限**：预估换手对应的成本不得超过收益量级。
4. **登记入册**：写入因子登记表，含定义、方向、参数、提交日期。**登记后不得改名或改定义**——
   变更视为新因子（否则多重检验计数会失真）。

### 5.2 预注册研究假设

每个因子在评估前写下：预期方向、预期 IC 量级、评估窗口、判定门槛。
评估完成后不得修改假设文本，只能追加结论。这是与方案 A 共用的科研纪律，
但方案 B 要求它**机器可查**（因子登记表落库），而不是写在文档里。

### 5.3 多重检验校正

- 统计全部**尝试过**的因子数量（含放弃的），而非最终保留的数量。
- 对显著性采用 Deflated Sharpe Ratio 或 FDR 控制。
- 报告必须同时给出"未校正"与"校正后"的结论差异。

### 5.4 走查与样本隔离

- 开发 / 验证 / 测试三段，**未来数据不得进入信号计算**（既有方法卡已要求）。
- 参数只能在训练段拟合；测试段**只用一次**，且用后即封存。
- 报告样本外净值，而非全样本净值。

### 5.5 成本与可执行性

- 单边成本默认 10 bps，同时展示 5 / 10 / 20 bps 敏感性（沿用既有约定）。
- 涨跌停不可买入、停牌不可交易、T+1 约束必须建模，否则回测不可执行。
- 报告必须包含换手率与"无法成交比例"。

### 5.6 停用规则（预先写死）

| 触发 | 动作 |
|---|---|
| 样本外 IC 均值 95% 置信区间包含 0 | 因子停用 |
| 组合净收益扣除成本后不显著优于基准 | 组合停用 |
| 走查期间 IC 符号翻转 | 因子降级并复核先验逻辑 |
| 实盘/纸上交易与回测偏离超过预设阈值 | 暂停并排查实现差异 |

## 6. 验收标准

| 维度 | 可证伪的判据 |
|---|---|
| 可复现 | 同一 `(日期, 股票池, 因子集, 参数)` 重复运行结果逐位一致 |
| 无未来函数 | 时点截断守卫测试通过；财务因子只使用已披露数据；无未来除权日被应用 |
| 无幸存者偏差 | 幸存者偏差程度已量化并在报告中披露 |
| 因子有效性 | 至少一个因子的样本外 IC 均值显著非 0，且校正后仍显著 |
| 组合有效性 | 组合净收益（扣 10 bps 单边成本）显著优于同期买入持有基准 |
| 可执行性 | 含涨跌停/停牌/T+1 约束的回测与无约束版本的差异已量化 |
| 可追溯 | 每只候选可回溯到因子值与数据快照 sha256 |

**若以上"因子有效性"或"组合有效性"不达标，正确产出是明确报告"未发现显著优势"**——
这也是合格的科研结论，不得通过继续调参来"修复"。

| 阶段 | 工期 | 交付物 |

| B2 因子研究流水线 | 3–4 周 | `factorlab/`（IC/IR、分位、走查、显著性）、因子登记表落库 |

## 8. 风险与失效条件

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| **找不到显著因子** | 中高 | 产出"无优势"结论 | 这是合法结论；预先接受，不要靠调参挽回 |
| 幸存者偏差严重 | 中 | 全部历史统计高估 | B1 第一项工作即量化；必要时缩短样本期 |
| `disclosed_at_ms` 不可靠 | 中 | point-in-time 退化为近似 | 退回"`period_end_ms` + 固定滞后"并披露 |
| 财务只有年报口径 | 已知 | 无法做季度因子 | 只用年度因子；或先落实 P0-4.1(a) 重建数据集 |
| 多重检验失控 | 中 | 虚假发现 | 5.1 登记制 + 5.3 校正 |
| 成本与可执行性被低估 | **高** | 回测收益不可实现 | 5.5 强制建模涨跌停/停牌/T+1 与 20bps 敏感性 |

## 9. 与既有资产的关系

方案 B **不推倒 FinSight**，而是重新分配职责：

| 既有资产 | 方案 B 中的角色 |
|---|---|
| `market_warehouse/` | 因子计算的唯一数据底座 |
| `strategy_experiments` / `strategy_reviews` | 单标的层的评估与晋升阶梯，**保留** |
| `advisor/ledger.py`、`research_track.py` | 建议与预测的双轨登记，**保留**（审计资产） |
| `_enrich_card()`、`_recommendation_tier()` | "LLM 不得抬档"的守卫，**保留** |
| `advisor/graph.py` 的多分析师/辩论链 | 收缩为解释层；深度模式可保留但不再影响方向 |
| `portfolio/backtest.py` | 从死代码变为组合层核心 |
| `advisor/algorithms/f_score.py`、`zscore.py` | 直接成为财务因子 |

## 10. 选它的代价

1. **放弃"AI 选股"的叙事**。对外它不再是"会荐股的 AI"，而是一套量化排序系统 + 解释器。
2. **2–3 个月才出第一个候选池**，6–9 个月才出判定。
3. 需要**统计与量化能力**：IC/IR、走查、Deflated Sharpe、多重检验不是可以糊弄过去的环节。
4. 大概率最终结论是"未发现显著优势"——A 股日频公开因子的有效性本就困难。
