# 风控层与策略级验收：三条阈值已过，卡在「回撤持续」

> 用户 2026-09-15 重新定义了目标（**以此为准**）：不追求百分百胜率，要「**大概率**能赚钱 +
> 符合常规股市交易逻辑」的一套打法，**不考虑**黑天鹅与异常波动（= 不去预测它），
> **外加风控机制**：即使不赚钱也要能基本保本或少亏。
> 并确认了四条容忍度：**最大回撤 ≤20%、单年最差 ≥−10%、回撤最长持续 ≤365 天、扣成本后期望 >0**。
>
> 本文记录把它落成工程的第一轮：**风控层**（D71）+ **验收判据**（D70）。

## 0. 一句话结论（先人话，再数字）

**四条阈值里已经过了三条**（期望为正、最大回撤、单年最差），**唯一卡住的是"回撤最长持续"**：
两条策略最惨的一次都要 **586–792 天**（约 1.6–2.2 年）才回到前高，而你要求的是 365 天。
**风控档位确实有用**：保守档下两条策略都是**收益更高、回撤更小**。

## 1. 风控层做了什么（每条都写明拦什么）

`strategy/models.py` 的 `RiskProfile` 是**声明式档位**，与信号解耦——同一个信号配不同风控，
结果差异往往比换信号还大：

| 规则 | 拦什么 | 实现位置 |
|---|---|---|
| 单笔止损 8%（保守档） | 一笔亏到止损线就走 | `strategy/backtest.py` 阶段 2（用当日 `low`；跳空则按开盘价成交） |
| **组合**回撤熔断 20% | 组合净值从峰值跌破阈值 → 暂停开新仓 20 个交易日 | `portfolio/backtest.py`（**只有那里有组合净值**） |
| 流动性门槛 1 亿 | 入场当日成交额不足 → 不买 | 入场分支（成交额**缺失时不假装达标**，也计入统计） |
| 涨跌停不可成交 | 开盘跳空 ≥9.5% → 买不进；≤−9.5% → 卖不出（**止损也成交不了**） | 入场与止损两处 |
| 波动率闸门 | 高波动不新开仓（既有 `volatility_gate_v1`） | 特征层 |
| 止损后再入场冷静期 5 日 | 防止同一条件反复进出（来回挨打） | 入场分支 |

三个档位：`risk_none_v1`（对照）/ `risk_conservative_v1`（上面这套）/ `risk_loose_v1`（止损 15%）。

**可审计**：每次回测都报 `risk_stats`（进场几次、止损几次、涨跌停拦了几次、流动性拦了几次、
熔断暂停几天），交易记录带 `exit_reason`。

### 1.1 数据补齐
日 K 原先只有开/收，做不了止损与流动性判断。`PriceBar` 增加可选 `low/high/turnover`，
`local_bars` 从 `daily_k` 取原值后**按「复权收盘 ÷ 原始收盘」缩放**到与复权序列同一空间——
不缩放的话除权日附近 `low` 会比复权价低一大截，**止损会被机械跳空误触发**
（与 `19` 号文档的配股口径错误同类）。实测 600519.SH 的 2427 根 K 线：`low ≤ close ≤ high` 全部成立。

## 2. 一个真 bug：熔断死锁（**本轮最重要的教训**）

第一版把回撤熔断写成「回撤收敛到一半以内才恢复」，并把 20% 这个**组合**口径的阈值
实现在**单标的**层。实测症状非常隐蔽：**逐年收益 2023–2026 全是 0.00%**，
保守档累计从 +87% 掉到 **−2%**——看起来像"风控太保守所以不赚钱"，实际是：

> 熔断触发后空仓 → 净值不动 → 回撤永远不收敛 → **该标的从此再不交易**（死锁）。

两处都改了：①恢复机制改成**时间界**（暂停 N 个交易日后自动恢复），并把
`breaker_cooldown_days` 约束为 ≥1（想配一个"永不恢复"的熔断会被模型直接拒绝）；
②熔断移到**组合层**（用户给的 20% 是组合回撤，单标的净值不是那个东西）。
修好后同一套风控**收益更高、回撤更小**（trend 62%→86%，回撤 −18%→−13%）。

**为什么值得写进文档**：这个 bug 不报错、不抛异常，只是"悄悄不再交易"。
守卫测试见 `tests/unit/test_risk_and_acceptance.py::test_breaker_must_be_time_bounded`。

## 3. 验收判据（D70）

`strategy/acceptance.py` 的 `evaluate_acceptance()` 把"这套打法能不能用"变成六条**可复算**检查，
每条都返回实测值 + 人话原因：

| 检查 | 阈值 | 来源 |
|---|---|---|
| 扣成本后为正 | >0 | 用户 |
| 最大回撤 | ≤20% | 用户 |
| 单年最差 | ≥−10% | 用户 |
| 回撤最长持续 | ≤365 天 | 用户 |
| 不靠少数几天 | 剔掉最好那天仍为正 | 我加的（防"年化好看全靠两天"） |
| 样本外最后 20% 不崩 | >−10% | 我加的（沿用既有 60/20/20 切分） |

⚠️ **评价里绝不剔除历史上的暴跌段。** 用户说"不考虑黑天鹅"指的是**不去预测它**，
不是**把它从成绩单里删掉**——删掉就等于系统性低估回撤。风控的作用是扛过去，不是装作没有。

## 4. 判读（诚实部分）

**可以说的**：

1. 风控档位**有效**：两条策略在保守档下收益更高、回撤更小（不是"为了安全牺牲收益"的取舍）；
2. 你的四条阈值里，**期望、最大回撤、单年最差三条已经满足**——两个策略都不是"亏钱的玩法"；
3. 所有组合都在**扣了双边成本**之后仍为正。

**不能说的 / 卡住的**：

1. **回撤持续这一条不过**（保守档 730 / 586 天 vs 要求 365 天）。这是当前的**唯一瓶颈**，
   而且它不是"收益不够"，是**A 股长多策略的恢复期本来就长**。两条出路：
   ①加一条"下跌市不交易"的规则（用指数趋势/波动率判断）把回撤期缩短；
   ②与你重新商量这个阈值（365 天对长多策略偏严——这是实测结论，不是推脱）。
2. ⚠️ **与「等权买入持有」的对比不可信**：那条基线在同一区间是 **+530%**，但股票池是
   **按 2026-09-04 的流动性挑的**（事后选择 + 幸存者偏差，与 `23` 号 §5 量化过的偏置同源）。
   在修掉股票池的**时点选择偏置**之前，**不得**据此说"买入持有更好"或"策略没用"。
3. 样本只有 20 只标的、两条既有策略；**没有**做过参数敏感性、也没做过滚动窗口的样本外检验。
