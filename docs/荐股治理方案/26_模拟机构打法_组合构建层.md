# 模拟机构打法（一）：组合构建层 + 两个把前面结论推翻的实测缺陷

> 用户 2026-09-15 的方向（**以此为准**）：在当前可做到的基础上**模拟机构打法**——
> 综合「个人散户现实可做的操作 + 当前数据基础 + 当前算法基础」。
>
> 本文记录第一轮：**组合构建层**（把"买哪些"变成"各买多少钱"）。
> 结果是**一半成功、一半失败，而且顺手挖出两个把前两轮结论推翻的缺陷**。

---

## 0. 一句话结论

机构做组合时真正在做的三件事，逐条对照我们的实测结果：

| 机构在做什么 | 散户能不能抄 | 我们的**实测**结果 |
|---|---|---|
| **① 分散**（多标的、多行业） | 能（但受资金量限制） | ❌ **扩大股票池没有降低风险**：流动性前 20 → 前 50，趋势策略最大回撤 **−29.95% → −46.75%**（因为前 50 里混进了波动更大的中小票） |
| **② 风险预算**（等风险贡献、按波动分配） | 能，零新增权限 | ❌ **没有稳定效果**：`inverse_vol` / `equal_risk` 与等权的差异在两个股票池、四档风控之间**符号来回翻**（同一格 +34pp，另一格 −18pp）→ 按噪声处理 |
| **③ 风险/仓位目标**（波动率目标） | 能 | ✅ **是唯一一个方向稳定的机制**：最大回撤 −29.95% → **−15.98%**（前 20）、−46.75% → **−21.98%**（前 50）；最长回撤期 991 → **473 天**、815 → **568 天**；收益基本不损失（345.7% → 350.2%；369.3% → 393.7%）。**Calmar 大致翻倍** |

**顺带挖出两个缺陷，都是"不报错、只让数字变好看"的类型，且都推翻了前两轮的结论**：

- **缺陷 A（已修）**：行业标签写成占位符 `未分类` 时，"行业上限 30%"退化成**总仓位上限 30%**。
  → 前两轮所有成绩都是在**最多 30% 仓位**下取得的，而对照的买入持有是满仓。
- **缺陷 B（已修）**：交易日取所有标的的**交集**，于是**股票池越大、可用历史越短**
  （top-50 只剩 591 个交易日，年化被算成 75%、"单年最差"变成 **+29.7%**）。

**因此我必须收回前两轮的两句话**（见 §5）。

## 1. 散户现实可做的操作清单（这一层为什么这么设计）

模拟机构打法第一件事是**先划清边界**：哪些机构动作散户根本做不到，别浪费时间。

| 机构动作 | 散户 | 依据 |
|---|---|---|
| 做空个股 / 融券对冲 | ❌ **做不到** | 同花顺手册里"融券" **0 次命中**，没有券源数据 |
| 股指期货对冲 | ⚠️ 门槛高（50 万 + 考试），本轮不做 | 手册有 `/api/futures`，但没有落库；且要先建基差/展期成本模型 |
| 加杠杆 | ❌ 不做（用户目标是保本） | 仓位上限硬编码 1.0 |
| 算法下单降低冲击成本 | ❌ 做不到 | 无分钟数据 |
| 另类数据 | ❌ 做不到 | 无数据源 |
| **分散** | ✅ 能（1000 万以下受流动性限制） | 已有流动性门槛 |
| **按风险分配金额** | ✅ **能，且零新增权限** | 只需要改"每只买多少钱" |
| **仓位/波动率目标** | ✅ 能 | 上一轮已实现 |
| **控制换手（不交易区）** | ✅ 能 | 本轮实现 |

**结论：散户能抄的只有后四条。本文就是把它们逐条做完、逐条测掉。**

## 2. 组合构建层做了什么

新模块 `backend/app/portfolio/construction.py`（全部可复算、无前视）：

| 机制 | 做法 | 为什么需要 |
|---|---|---|
| **等风险贡献（ERC）** | 循环坐标下降解 `σ_ii·x_i² + x_i·Σ_{j≠i}σ_ij·x_j = 1`，取正根 | 让每只票对组合波动的贡献相同。**长期多约束自动满足**（正根必为正），不需要额外投影 |
| **逆波动率** | 权重 ∝ 1/σ（只用对角项） | 对照：如果它和 ERC 结果一样，说明**协方差的非对角项没有信息量**，那就不该维护更复杂的代码 |
| **收缩估计** | 样本协方差向对角矩阵收缩（默认 0.5） | 20 个标的 / 120 天样本，非对角项基本是噪声 |
| **换手带** | 目标与当前权重之差 < 带宽就不调仓 | 机构的不交易区；对应散户"每次调仓都要付钱" |
| **上限注水法** | 超限部分**再分配**给还有空间的标的 | 只截断会让总仓位凭空变小（约束偷偷改了暴露度） |
| **审计** | 报出**实际风险贡献**（不是权重） | ERC 声称"风险贡献相同"，就必须拿这个数字验 |

**为什么不做均值-方差优化**：它需要**预期收益**输入，而本项目前面几轮的全部努力都**没有找到**
任何经过验证的预期收益（因子 IC 最大 |t|=0.81、事件研究全部未过门槛）。硬套一个拍脑袋的
预期收益会得到"伪精确"的权重。**风险层面不需要预测**——协方差可以从历史稳健估计，
这是唯一诚实的优化目标。

## 3. 缺陷 A：占位行业把"行业上限"变成了"总仓位上限"（**已修**）

### 3.1 怎么发现的

写组合构建的测试时顺手验算 `allocate_candidates`，发现：

```
6 只标的（行业全部 = "未分类"）、单票上限 10%、行业上限 30%
→ 目标权重 = 3 只 × 10% = 总仓位 0.30
```

而验收脚本 `scripts/run_strategy_acceptance.py` **正是把 20 只标的的行业全部写成 `未分类`**。

### 3.2 后果

前两轮（`25` 号文档 · 风控层 / 波动率目标）的**全部成绩都是在最多 30% 仓位下取得的**，
而报告里对照的"等权买入持有"是**满仓**。两件事同时被扭曲：

1. **绝对收益被压低**：同样信号下，30% 仓位 vs 95% 仓位差三倍多。
2. **回撤被"抹平"**：30% 仓位下的回撤天然只有满仓的约三成——所以"最大回撤 ≤20%"看起来很轻松。

修完之后同一格（`trend_20_60_v1` × 无风控）的变化：

| | 修前 | 修后 |
|---|---|---|
| 累计收益 | 62.39% | **345.67%** |
| 最大回撤 | −18.18% | **−29.95%** |
| 回撤最长持续 | 792 天 | **991 天** |
| 平均仓位 | （30% 隐性上限） | 45.6% |

**"最大回撤"从"轻松通过"变成"不通过"。**

### 3.3 修法（两条，缺一不可）

1. **未知行业不参与行业约束**：`industry_key()` 把 `""` / `未分类` / `unknown` / `none` / `null`
   统一归一化为 `None`，表示"不参与行业约束"。给一个我们其实不知道的标签施加约束，
   比不施加更糟——它会把一条规则偷偷变成另一条规则。守卫：
   `test_unknown_industry_must_not_act_as_a_total_position_cap`。
2. **总仓位变成显式参数**：`max_total_exposure`（默认 **0.95**，留 5% 现金覆盖换手成本），
   并在报告里落 `portfolio_limits`。同时**每个组合都报出实际仓位**
   （`avg/min/max_invested_weight_pct`）——不报的话，"收益为什么低"会被误判成信号不行。

## 4. 缺陷 B：交易日取交集 → 股票池越大、历史越短（**已修**）

### 4.1 怎么发现的

把股票池从流动性前 20 扩到前 50（想测"机构的第①条：分散"），结果**离谱得不像话**：

| | 前 20 | 前 50（修前） |
|---|---|---|
| 等权买入持有累计 | 529.9% | 491.3% |
| 等权买入持有**年化** | 37.0% | **113.1%** |
| 趋势策略"单年最差" | −2.6% | **+29.7%**（全为正） |

"单年最差都是正的"这个数字本身就是警报。查下去：`_common_dates` 取的是所有标的交易日的
**交集**——50 只标的里只要有少数几只 2019 年后才上市，整段回测就被压到那之后。
实测只剩 **591 个交易日**（约 2.4 年，正好是一段牛市），年化自然被算成 75%–113%。

**这不叫分散，这叫换了个样本。**

### 4.2 修法

- `_trading_calendar` 改为**并集**（全样本交易日）。
- **停牌处理**：某只标的当天没有 K 线 → 视同停牌，市值不变、**当天不可交易**。
  三个地方都要处理：过夜标记、调仓、收盘结算。
- 关键细节：停牌标的钉住的市值**要占掉总仓位额度**，否则"钉住的旧仓位 + 新建仓位"
  会超过上限 → 直接触发借款报错（第一版就踩到了，`RuntimeError`）。
- 等权买入持有基线同步支持**参差不齐的上市时间**：晚上市的标的在它开始交易那天才投入。

修完后两个股票池的样本期间才可比（买入持有年化 36.2% / 33.2%，都是约 9 年）。

守卫：`test_universe_size_must_not_shrink_the_sample_period`、
`test_suspended_symbol_is_not_traded_at_a_nonexistent_price`。

## 5. 我必须收回前两轮的两句话

| 原话（`25` 号文档） | 现在的实测 | 判定 |
|---|---|---|
| "四条阈值里**已经过了三条**（期望为正、最大回撤、单年最差），唯一卡住的是回撤持续" | 修完缺陷 A 之后，**最大回撤也不通过**（趋势策略 −29.95%） | ❌ **收回**。正确说法：只有"期望为正"和"单年最差"过，**回撤深度与回撤期两条都不过** |
| "**风控保守档让两条策略收益更高、回撤更小**" | 现在：`trend` 无风控 345.7% vs 保守档 173.9%（**更差**）；`reversal` 40.6% vs 60.2%（更好）→ **符号随策略翻** | ❌ **收回**。正确说法：保守档的收益效果**方向不稳定**，不能说"有效" |
| "波动率目标在**趋势策略上是净亏的**（Calmar 0.834 → 0.632）" | 现在：无风控 Calmar 0.633 → 波动目标 10% **1.195**（前 20）；0.423 → **0.931**（前 50） | ❌ **收回**。那也是在 30% 仓位下量出来的。正确说法见 §6 |

**这三条都是同一个根因**：在被隐性压到 30% 的仓位上做的比较，杠杆被压平之后，
原本的小差异被放大/翻转。**教训（新决策 D76）：任何"策略 A vs 策略 B"的比较，
必须先报出两者的实际仓位，仓位不一致的对比直接作废。**

## 7. 三个诚实结论（含一个"没有效果"）

### 7.1 ✅ 波动率目标是唯一方向稳定的机制

跨两个股票池、两个策略、四档风控，**方向一致**：

- 最大回撤：前 20 从 −29.95% 压到 −15.98%；前 50 从 −46.75% 压到 −21.98%
- 最长回撤期：前 20 从 991 压到 473 天；前 50 从 815 压到 568 天
- 收益：基本不损失（前 20：345.7% → 350.2%）
- **Calmar（年化 ÷ 最大回撤）大致翻倍**：前 20 0.633 → 1.195；前 50 0.423 → 0.931

**这是本项目到目前为止唯一一个"跨样本、跨策略、方向稳定"的有效机制。**

### 7.2 ❌ 按风险分配金额（ERC / 逆波动率）没有稳定效果

同样约束、同样信号，只换权重方案：

| 格子 | 等权 | 等风险 | 差 |
|---|---|---|---|
| 前 20 · 波动目标 15% · trend | 334.0% | 389.0% | **+55pp** |
| 前 20 · 波动目标 10% · trend | 350.2% | 338.4% | −12pp |
| 前 50 · 波动目标 10% · trend | 210.7% | **393.7%** | **+183pp** |
| 前 20 · 无风控 · reversal | 40.6% | 40.3% | −0.3pp |

**符号来回翻、幅度不可预测。** 按 A.2（所有比较都要计入）与"不做事后挑"的规矩，
**正确结论是"未检出效果"，不得挑最好看的那一格说事。**

可以解释的原因：我们的组合里**平均只有 5–10 只持仓、且经常不满仓**（见 §7.3），
在这种规模下"单票上限"往往先于"风险预算"起作用——上限把 ERC 想要的极端权重直接裁掉了。
`test_portfolio_construction_changes_weights_and_reports_audit` 就是在记录这个现象。

### 7.3 ⚠️ 两个比"怎么分钱"更大的结构问题

1. **平均仓位只有 27%–66%**：策略很少同时对很多标的发出信号，所以组合经常大部分是现金。
   收益是在"部分仓位"上取得的，**与满仓买入持有的对比始终不可比**（这一条在缺陷 A 修完后**依然存在**）。
2. **年化换手 860%–11700%**：按 10bps/边算，成本 0.9%–11.7%/年。
   实测**换手带（不交易区）几乎没用**——因为换手来自"信号进出"（权重 0 ↔ 正），
   而不是"权重微调"。要给散户用，必须从**信号层**降频，而不是在权重层打补丁。

| 顺序 | 内容 | 为什么是它 |
|---|---|---|
| 1 | **时点股票池**：按各评估日的时点流动性重建，而不是用 2026-09-04 的排名 | 买入持有在样本里是"年化 36.2%"——这个数字本身就是幸存者偏差。**不修掉它，所有"跑赢基准"的话都不能说** |
