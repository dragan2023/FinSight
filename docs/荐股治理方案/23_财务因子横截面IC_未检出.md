## 0. 一句话结论

**6 个财务因子在候选池样本内、两种前向口径下，全部与噪声无异。**

| 因子（方向） | 主检验：可成交口径 `next_open` | 对照：`close_T` | 族级门槛 |
|---|---|---|---|
| `f_score`（Piotroski，high） | **+0.0034（t=+0.27）** | +0.0024（t=+0.20） | 3.197 |
| `f_score_ratio`（high） | +0.0036（t=+0.29） | +0.0026（t=+0.20） | 3.197 |
| `roa`（high） | −0.0031（t=−0.21） | +0.0002（t=+0.01） | 3.197 |
| `assets_debt_ratio`（**low**） | +0.0055（t=+0.37） | +0.0094（t=+0.63） | 3.197 |
| `sale_gross_margin`（high） | −0.0047（t=−0.32） | −0.0018（t=−0.13） | 3.197 |
| `total_assets_turnover_ratio`（high） | −0.0091（t=−0.81） | −0.0080（t=−0.70） | 3.197 |

- 105 个评估日（月度采样，2016-12 → 2026-08），每日期样本数中位 **163**；
- **最大 |t| = 0.81**，而族级门槛是 **3.197**（声明的 36 条比较）→ **没有任何因子过门槛**；
- **分时段符号翻转**：2016–2020 的点估计偏正（`f_score` +0.028，t=1.40；毛利率 +0.044，t=1.69），
  2021 起转为偏负（`f_score` −0.011，t=−0.71；毛利率 −0.035，**t=−2.15**）。
  一个方向不稳定的点估计，比"接近 0"更不像信号。

> **这是合格结论**（`06` §10 第 3 条）：**未发现显著优势**，不需要、也不允许通过调参去"修好"它。
> 但它**不等于"证明财务因子无效"**——见 §4 的功效说明。

## 1. 预注册（**先登记再跑**）

在看任何数字**之前**写入 `hypothesis_registry`：

- 6 条因子条目（`financial:f_score@v1` … `financial:total_assets_turnover_ratio@v1`，
  同族 `financial_fundamentals`，**方向逐条写死**）；
- 1 条设计条目（`financial_factor_study_design@v1`）：样本域、as-of 纪律、评估日频率、
  前向收益口径、统计量、安慰剂角色、分时段复现、**声明的 36 条比较**与门槛、禁止事项、
  以及**样本选择偏置的预先声明**。

登记脚本：`scripts/governance_register_financial_factors.py`（幂等；已绑定当前批次 `36c1c02a`）。

**为什么只登记"水平"而不登记"变化量"**：ΔROA / Δ杠杆 / Δ毛利率 这些变化量**已经在 F-Score
的九项判定里用掉了**；再单独登记等于把同一份信息数第二遍，推高族级计数而信息量不增（A.2 要防的
正是"用搜索空间换显著性"）。

## 2. 方法（每条都在登记里，不在这里改）

| 项 | 做法 |
|---|---|
| **样本域** | 本地财务数据集（202 只）× 当日通过**既有股票池规则**的标的（复用 `screener.service.eligible_rows`，不另写一套） |
| **as-of** | 每个评估日 T 只用 `available_from_ms ≤ T` 的报告期；**各张报表必须取共同期**（见 §6 第 1 条） |
| **Δ 类对照期** | 一律取**上年同季**（季报累计口径下，同季同比才是同一口径的比较） |
| **评估日** | 每月最后一个交易日；**报告期众数占比 < 90% 的日子剔除**（跨 YTD 窗口的比率不可比） |
| **前向收益** | 主检验 = `next_open`（T+1 开盘 → T+20 收盘，D53 的可成交口径）；`close_T` 作对照 |
| **统计量** | Rank IC（Spearman，方向已折进偏好分）按评估日聚合后的**时间序列 t 值** |
| **安慰剂** | 逐标的置乱 200 次，**仅机制自检**（`13` 号文档已纠正：它的零分布离散度只有真实的 1/4–1/7，当门槛会系统性放大通过率） |
| **多重检验** | 6 因子 × 2 口径 × (全样本 + 2 分时段) = **36 条**；族级先验 0 → 门槛 **3.197** |

## 3. 结果

### 3.1 评估日与样本

| 项 | 值 |
|---|---|
| 候选月度交易日 | 121 |
| **采用** | **107**（剔除 14：其中 4 个是 2016-09/10/11 —— 财务数据第一期的闸门还没开，样本为 0；其余 10 个是报告期众数占比 < 90%） |
| 实际参与统计 | **105**（另 2 个日期有效样本 < 20 只） |
| 每日期样本数中位 | **163** 只 |
| 报告期众数占比中位 | **1.00**（剔除规则生效后，剩下的日子报告期完全统一）

### 3.2 主检验（可成交口径）

见 §0 主表：**最大 |t| = 0.81**（总资产周转率），`f_score` 只有 +0.0034（t=0.27）。

### 3.3 分时段复现（均值 IC / t）

| 因子 | 2016–2020（38–40 日） | 2021–（65 日） |
|---|---|---|
| `f_score` | **+0.0282 / t=1.40** | **−0.0111 / t=−0.71** |
| `f_score_ratio` | +0.0292 / t=1.42 | −0.0113 / t=−0.71 |
| `roa` | +0.0333 / t=1.23 | −0.0256 / t=−1.57 |
| `assets_debt_ratio` | +0.0178 / t=0.78 | −0.0020 / t=−0.10 |
| `sale_gross_margin` | +0.0438 / t=1.69 | **−0.0345 / t=−2.15** |
| `total_assets_turnover_ratio` | −0.0246 / t=−1.40 | +0.0004 / t=+0.03 |

**符号在半数因子上翻转**（F-Score、ROA、毛利率、杠杆），且**两段都没有一个因子过门槛**。
`2021-` 的毛利率 t=−2.15 过了逐检验 1.96，但：①离门槛 3.197 差得远；②**符号与登记的方向相反**；
③它是 36 条比较里的一条——按多重检验纪律不得当作发现。

### 3.4 门槛与计数（防止"算松"）

```
声明比较条数 = 6 因子 × 2 口径 × 3 区间 = 36
族级先验 = 0（financial_fundamentals 是新族）
族级 Bonferroni 门槛 |t| ≥ 3.197
```

本轮这 36 条**必须计入下一轮同族**的族级先验（报告 JSON 里 `multiplicity.family_prior_statistics` 已写明）。

## 4. 判读：未检出，**但不等于证明无效**

**可以说的**：

1. 在这 105 个评估日、每日期约 163 只标的的样本里，**6 个财务因子的水平值与未来 20 日收益
   没有可检出的横截面关系**（两口径最大 |t| = 0.81）；
2. 点估计的**符号在前后两段之间翻转**，与"稳定的小信号"不符；
3. 可成交口径与 `close_T` 口径的结果几乎一致（差的量级 ≤0.003）——这一点与 `21` 号文档的
   涨停池结论**形成对照**：那里"买不到"吃掉了全部效应；这里买入点的挪动几乎不改变结论，
   因为财务因子与"封板当日的价格失衡"无关。

**不能说、但很多人会误读的一条（功效问题）**：

- 本样本下，`IC` 的逐日 sd ≈ 0.126，105 个评估日 → 均值 IC 的标准误 ≈ **0.0124**，
  95% 置信区间约 **±0.024**。也就是说：**一个真实的均值 IC ≈ 0.02 完全落在置信区间内**，
  而 0.02 在文献里已属"有意义"的量级。
- 所以准确表述是：**在现有样本与门槛下未检出**，**不能**说"财务因子已被证伪"。
  要真正排除 0.02 量级的效应，需要更长的样本或更宽的横截面（见 §8）。

**样本外的限制**（另见 §5）：结论只适用于**这个已选定的高流动性样本**。

## 5. 样本选择偏置（登记时已声明，必须一并阅读）

**问题**：这 202 只标的是按 **2026-09-04 的成交额前 200** 选出来的，却被用来评价 2016 年以来的
历史——标的层面存在「**以未来流动性选样**」的偏置。

**量化**（105 个评估日全部有指标，报告里逐日留档）：

| 指标 | 值 |
|---|---|
| 样本在**当日全市场**成交额分位的中位数 | **0.8903** |
| 第 10 百分位 | 0.8453 |
| 最小 / 最大 | **0.801 / 0.9806** |

**读法**：全市场约 5000 只标的里，这 202 只**从来没有掉到全市场前 20% 之外**（最小值 0.801），
中位数在 **89 分位**。也就是说：这是一个**「最活跃的大票」样本**，IC 是在这个条件下测出来的——
它与「全市场选股」完全是两回事。这个偏置**不能被后续统计消除**，只能披露 + 限制结论范围。

**结论边界**：只能表述为「在这个已选定的高流动性样本内未检出」，**不得**外推为全市场结论；
样本内的 IC 也不等于全市场 IC。若将来要做全市场评价，必须**先按各评估日的时点流动性重建股票池**
并重新同步那些标的的财务数据（D36 的收窄范围是当时的折中，现在成了这条结论的天花板）。

## 7. 决策（D64–D66）

| # | 决策 | 理由 |
|---|---|---|
| **D64** | **财务因子的"当期水平"判定为未检出优势**，**不得**作为 C3 的信号源；本条登记为**已评价**，不接受"换个窗口再跑一遍"式的重复评价 | §3：两口径最大 \|t\| = 0.81 vs 门槛 3.197；分时段符号翻转。按 D19/`13` 号的纪律，未过门槛就是未过门槛 |
| **D65** | 财务数据的下一步价值在**条件性/交互性用法**（如"低估值 × 高 F-Score"、"F-Score × 涨停池事件"），但那**属于新假设**，必须各自**新开 reference 预注册**后才能跑 | 直接把没检出的因子换个组合再跑，就是 A.2 明令禁止的"用搜索空间换显著性"。且 `21` 号文档已示范：同样的数据换个口径能得出完全不同的结论，所以口径必须先登记 |
| **D66** | **凡使用本数据集做评价，报告必须常驻披露样本选择偏置的量化指标**（逐日留档 + 汇总），并写明"不得外推" | §5：偏置是结构性的（按未来流动性选样），不写就等于把有条件结论冒充无条件结论 |

## 8. 限制与仍未解释（诚实挂着）

1. **功效不足**（§4）：105 个评估日、每日期 163 只，只能排除 |IC| ≳ 0.025 的效应；
   0.02 量级的真实效应**测不出来**。要提升功效需要更长样本或全市场横截面。
2. **样本选择偏置**（§5）：结构性偏置，量化后仍不能消除。
3. **季报是否累计口径仍未证实**（`22` §5 第 3 条）：本轮用"同季同比"规避，`api_basis` 如实记为
   `quarterly_cumulative_unknown`。
4. **不含退市标的**（行情库本身不含）：负向效应被低估。
5. **未计交易成本**：IC 只是相关性，不是可实现收益。
6. **未控制行业与市值**：横截面 IC 里混着这些未控制维度的差异。
