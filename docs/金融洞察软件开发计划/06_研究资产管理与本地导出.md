# 06 — 研究资产管理与本地导出

> 历史未执行方案，已由[新功能计划](../金融研究功能开发计划/00_计划索引.md)取代；下文保留作历史设计参考，不再作为实施指令。

## 1. 阶段摘要与前置阅读

优先级 P1；工作量中，3 个实现验证批次；直接依赖03，不强制依赖04/05；目标：报告、笔记与关注列表可长期保存、检索和安全导出。

前置阅读：`backend/app/research/models.py`、`repository.py`、`evidence_repository.py`、`storage.py`、`api/reports.py`、`frontend/src/pages/Reports/ReportDetail.tsx`。若04/05已完成，只通过统一报告字段支持其数据，不读取它们的私有内部实现。

## 2. 任务详情

### 2.1 研究资产与版本

新增 `backend/app/research/watchlist_service.py`、`export_service.py`、`api/watchlists.py`，扩展reports/repository。SQLite增加watchlists、watchlist_items和notes，报告新版本关联原报告；证据表仍使用02的定义。

关注列表只含标的身份、名称、备注、时间，不存数量、成本、账户资金。报告按问题关键词、标的、日期检索，首版SQLite足够，不加向量库。用户笔记与供应商数据、模型结论分开标注。

重新研究创建新报告版本，不覆盖旧来源和数值；旧报告不是新事实的自动依据，跨报告事实必须回到原证据。添加本地软删除，明确清理时才删无引用证据，不自动清除用户历史数据。

### 2.2 安全本地导出与恢复

支持Markdown、HTML和指标CSV，固定模板组织问题、标的、时间、结论、数据表、限制、证据和非投资建议说明。HTML转义/消毒，禁止模型生成的脚本；CSV文本防公式注入，数值按类型输出，不误处理合法负数。

文件限定写入`data/exports/`，根据报告/导出ID查表下载，不接受任意本地路径。导出不含密钥、完整配置、签名URL、原始提示词、隐藏思维链或本地绝对路径。

缓存清理不能删除被报告引用的证据。证据文件丢失时明确提示，不请求最新数据冒充原证据。处理磁盘满、SQLite锁定和原子写失败；报告保存成功前不可返回成功状态。用备份副本恢复到测试目录，核对索引和证据hash，不在用户库上实验。

### 2.3 页面与API

新增 `frontend/src/pages/Reports/index.tsx`、`components/Research/WatchlistPanel.tsx`、`api/watchlists.ts`，扩展报告详情页和api/reports.ts。

接口：GET `/api/reports`、POST `/api/reports/{id}/export`、GET `/api/reports/{id}/exports/{export_id}`、GET/POST `/api/watchlists`、POST/DELETE `/api/watchlists/{id}/items/{thscode}`。这些写操作只管理本地研究资产，复用01的会话/Origin/Host校验。

不默认外发报告或通知；外部数据与模型服务条款未核实前只声称本地研究能力，不声称商业再分发授权。用户导出不意味着授权应用自动上传。

## 3. 禁止事项与兼容性

不加入个人账户持仓、收益跟踪或组合优化；不自动发邮件/webhook；不将缓存TTL作为报告证据保留期。更新报告不能静默替换原结论，敏感模型配置不参与全文检索。

## 4. 验收标准

- [ ] 关注列表、报告版本、备注和搜索跨重启有效。
- [ ] Markdown/HTML/CSV导出保留来源、日期与限制，无脚本/公式注入和路径穿越。
- [ ] 删除缓存不损坏报告；证据缺失、写盘失败有明确错误。
- [ ] 新增 `tests/unit/research/test_exports.py`、`test_watchlists.py`、`test_retention.py`并通过。
- [ ] 浏览器/日志/导出中不存在数据或模型Key；没有自动外发操作。
