# 同花顺接口调研与能力边界

## 1. 调研来源与适用范围

本文件根据2026-08-31本次对话已经完成的官方Financial-API研究和有限账号探针重新整理，服务于FinSight新建路线，不复制旧项目架构。官方资料可能变化，实施时按目标端点重新核对；本轮项目初始化没有再次请求付费API或迁移Key。

上游入口：[HiThink-Tech/Financial-API](https://github.com/HiThink-Tech/Financial-API)、[REST契约](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/README.md)、[线上聚合说明](https://fuyao.aicubes.cn/llms-full.txt)。聚合说明适合检索，但不是OpenAPI机器契约。

## 2. 接入方式选择

FinSight选择后端REST薄适配，统一密钥、预算、缓存和证据。MCP适合独立聊天客户端，未来如使用需运行时工具发现和明确白名单，不直接向模型开放所有工具。Node CLI适合人工/离线批量任务，不作为Web请求中的子进程。Python toolkit与marketdb的目录/安装边界不同，不能假设安装marketdb就能导入远端toolkit。[MCP](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/mcp.md)、[CLI](https://github.com/HiThink-Tech/Financial-API/blob/main/hithink-finance-cli/README.md)、[Python](https://github.com/HiThink-Tech/Financial-API/blob/main/python/README.md)

现阶段无需全市场多年数据，因此不引入DuckDB和Market Dumps。以后确有容量需求再使用官方批量能力，避免逐股高频拉全市场。软件许可证不等于金融数据再分发许可，SDK根LICENSE与Python元信息也存在MIT/Proprietary文字差异，不将未经核实的授权写成承诺。[包元信息](https://github.com/HiThink-Tech/Financial-API/blob/main/python/pyproject.toml)、[LICENSE](https://github.com/HiThink-Tech/Financial-API/blob/main/LICENSE)

| 数据域 | 代表路径 | FinSight用途与限制 |
| --- | --- | --- |
| 标的 | /api/meta/tickers/search、list | 代码/名称消歧；保留完整thscode和资产类型 |
| 个股价格 | /api/a-share/prices/snapshot、historical | 显式标的快照与日线；历史start/end毫秒戳，单股，明确复权 |
| 财务 | /api/a-share/financials/income-statements、balance-sheets、cash-flow-statements、indicators | 三表与指标；期间/披露日分开，abilities数组与字符串值要解析 |
| 估值 | /api/a-share/valuations/snapshot | 当前固定五项PE/PB/PS/PCF，不支持历史估值分位 |
| 日历 | /api/a-share/calendar/trading-days | 公开范围为近一年，不能假设任意历史年份可查 |
| 指数/板块 | /api/a-share-index/catalog/ths-index-list、constituents/ths-stock-list、prices/snapshot、prices/historical | 当前成分、指数日线；无复权，代码不能按股票规则猜 |

## 5. 实测与文字契约的差异

1. 显式股票快照本次返回非空timestamp；文档存在为空的描述，所以解析器两者都接受，不把获取时间替代源时间。
2. 部分说明称业务响应恒HTTP200，但财务探针真实返回HTTP429/code429且无request_id；处理HTTP、业务码和缺字段要独立。
3. 日线实测顶层多出thscode/interval/adjust，允许附加字段但不放弃核心校验。
4. 财务period是否必填的文字有出入，本产品始终显式传入；季度单季/累计与未知指标单位未确认前不做推算。

统一协议参考[REST说明](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/README.md)，差异来自之前真实请求，不应被文档默认值覆盖。

## 6. 产品必须保留的限制

null不补零，负估值不取绝对值；百分比点和比值分开；快照没有名称时联合标的元数据，不自行编造。报告期、数据源时间、获取时间、单位、复权与来源证据随结果传递。基金新闻只有公开文章元数据，不能当研报全文服务。

分钟/tick/Level-2、港美股/期货和研报全文不属于当前公开MCP快照范围；检索中有某资产类别不代表具备其所有数据能力。数据不可用直接说明，不用模拟/静态数据冒充。[公开能力边界](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/mcp.md)

QPS、计费、数据再分发与外部模型处理许可没有得到本账号的完整证据；本地设置展示实际结果与产品预算，不写无限额度/免费或商业授权承诺。财务429只能说明请求受限，不能据此断言Key无效或套餐原因。
