# 01 — 基础工程与模型配置

## 1. 阶段摘要与前置阅读

优先级 P0；工作量中，3 个实现验证批次；直接依赖：项目初始化骨架；目标：建立没有金融业务也能正常启动的本机应用和安全模型设置。

前置阅读（现有）：`README.md`、`.env.example`、`requirements.txt`、`requirements-dev.txt`、`pyproject.toml`、`backend/app/__init__.py`、`frontend/README.md`、`scripts/README.md`。这些是当前实际存在的文件，下面运行与前端文件均为本阶段新增。

## 2. 任务详情

### 2.1 建立独立后端与安装基线

用 `.venv/Scripts/python.exe -m pip install -r requirements-dev.txt` 安装初始依赖，并运行 pip check。若真实兼容性失败，查明冲突后更新直接依赖版本，不复制旧环境解决。增加 `requirements.lock.txt` 固化本次干净安装实际使用的全部依赖。

新增 `backend/app/main.py`、`settings.py`、`dependencies.py`、`storage.py`、`api/system.py`、`api/model_config.py` 与必要包标识。配置采用 Pydantic 校验，环境加载用 python-dotenv，路径锚定项目根，不依赖启动工作目录。目录创建在启动时显式进行，不在任意模块 import 时产生用户数据。

FastAPI lifespan 创建/释放 httpx 客户端、服务和研究执行资源；使用 app.state 加明确依赖函数，不添加 DI 框架。启动主机默认为 127.0.0.1，端口来自 FINSIGHT_PORT；首版单 worker。

新增 `/health` 与 `/api/system/status`：健康仅判断本机服务，不自动请求同花顺或模型。缺 Key、无模型配置时应用和设置必须可访问。异常返回安全分类，不透传请求头/凭据/堆栈。

### 2.2 新建模型配置，不复制旧配置数据库

新增 `backend/app/model_config/models.py`、`service.py`、`repository.py`、`encryption.py` 和 `backend/app/agent/model_factory.py`。先支持一个活动配置，也允许保存少量命名配置；不开发供应商插件框架。

配置字段：id、name、base_url、model、encrypted_api_key、temperature、max_tokens、timeout、active。新库 `data/db/finsight.db` 中建 model_profiles 表，SQLite 使用外键、事务和版本号迁移；不依赖 Alembic/SQLAlchemy，除非出现明确需求。

用成熟 Fernet 加密：根密钥仅来自 FINSIGHT_ENCRYPTION_KEY；已有加密记录但根密钥缺失时显示不可解密，不自动生成替换密钥或输出新密钥。首次尚未配置根密钥时可通过环境配置调用模型，数据库保存能力明确不可用。本阶段新增 `scripts/init_local_secrets.py`：仅在没有根密钥且没有已有加密记录时生成根密钥，定向写入本地.env，不覆盖其他变量、不输出密钥；发现已有加密记录则拒绝重新生成。由用户主动运行，不能随应用启动执行。

浏览器只能看到 configured/masked 状态；凭据字段只写不读。空白更新表示不改 Key，清除使用显式 clear_api_key。连接测试区分连通、聊天与结构化工具调用支持；测试由用户触发，不自动遍历模型列表或消费额度。

模型工厂读取活动配置；允许使用 LLM_BASE_URL/LLM_MODEL/LLM_API_KEY 作为无数据库配置时的明确来源，不悄悄改用另一个模型。连接与关闭使用异步 SDK 生命周期，不阻塞 HTTP 事件循环。

### 2.3 创建前端、状态页与安全启动

在 `frontend/` 新建独立 Vite React TypeScript 工程，增加 Ant Design、React Query、Axios；初期不需要全局状态库或图表包。package.json 具备 dev/build/lint/test 命令；选用 Vitest 和 React Testing Library 测交互与数据状态，维护独立 package-lock。

新增 `frontend/src/App.tsx`、`api/client.ts`、`api/system.ts`、`pages/Home/index.tsx`、`pages/Settings/index.tsx`、`components/Layout/`。首页清楚显示尚未接入数据，不能用静态金融数值充当线上结果。只提供首页和设置导航，后续页面就绪再加入菜单。

Axios 明确响应解包后的真实类型，错误保留 category/request_id/retryable，不用 any 或吞掉所有错误信息。模型设置凭据不放 localStorage/sessionStorage。

新增 `scripts/start_backend.ps1`、`start_frontend.ps1`，采用前台模式便于用户停止；自动启动辅助后台时用隐藏窗口，仅管理自己启动的 PID。禁止按端口或 python.exe/node.exe 通杀。前端允许 origin、后端 Host 校验和 JSON 内容类型约束从本阶段加入，后续写操作沿用本机会话保护，不依赖 CORS 作为唯一鉴权。

## 3. 禁止事项与兼容性

不搬旧项目整目录、旧数据库或密钥；不把已安装包复制进新 venv；不创建交易代码占位。不能为通过构建关闭 TS strict/noUnused，不继承旧 titleColor 等未校验主题 token。初始研发只绑定回环地址，不自动部署公网。
