# 05 — 板块市场与基金研究

> 历史未执行方案，已由[新功能计划](../金融研究功能开发计划/00_计划索引.md)取代；下文保留作历史设计参考，不再作为实施指令。

## 1. 阶段摘要与前置阅读

优先级 P1；工作量大，4 个实现验证批次；直接依赖03，不依赖04的财务授权；目标：以相同研究流程覆盖指数板块、市场事件和基金披露。

前置阅读：`backend/app/market_data/models.py`、`service.py`、`hithink_client.py`、`agent/tools.py`、`research/models.py`与调研资料中的指数、特色、基金契约。若04已实现comparison，仅复用其通用期间校验；不能形成对04的隐含依赖。

## 2. 任务详情

### 2.1 行业概念与指数

扩展客户端和数据模型，接指数目录、当前成分、显式快照和日线；新增 `backend/app/analysis/market_summary.py`、`api/market_research.py`。

目录支持官方行业/概念等tag，保留`.TI`和标准指数代码；股票/指数分流。不传指数复权参数；当前成分不能当作历史成员用于重建过去组合收益。大目录在后端缓存/筛选，只将所选片段发送模型。

首版展示有限选中板块的区间表现、当前成分与研究入口，不实现ETF轮动或“热点自动交易”。指数快照必须有thscodes，不能靠无效分页参数拉全市场。

### 2.2 特色市场信息

接有限涨跌停池、按标的异动、热榜和龙虎榜解释；每次最多一页或5个用户选定标的。独立定义page/size、固定窗口和日期参数，不能把所有端点当通用offset分页。

供应商异动原因标为source_commentary，数字事实和Agent推断分别标识。没有事件、尚未就绪、接口失败是不同状态；当日异动不能承诺任意历史查询。热榜不变成买卖信号或自动通知。

### 2.3 基金公开资料与净值

扩展数据层，新增 `backend/app/analysis/fund_metrics.py`、`api/funds.py`。先接profile/detail、performance/nav、performance/returns、performance/drawdowns、portfolio/holdings、managers/detail和companies/detail；公开资讯仅使用news/article-list元数据。

fund_type严格区分otc/exchange/reits，基金身份来自搜索/档案而非猜测。公司/经理ID从响应获取，不由模型编造。基金资讯offset为不透明游标，原样回传，出现重复游标/无进展停止请求。

价格、单位净值、累计净值、区间收益与回撤按各自来源口径显示，不用净值简单涨跌冒充含分红总回报。基金持仓是公开披露且滞后，必须显示披露期/覆盖范围，不是用户账户。

第一版支持基金资料、净值图、公开持仓构成和有限基金比较；不实现份额修改、申赎、组合权重优化或账户盈亏。披露期不一致不能直接比较持仓重叠。

### 2.4 页面与能力验证

新增 `frontend/src/pages/Market/index.tsx`、`pages/Funds/index.tsx`、`api/marketResearch.ts`、`api/funds.ts`；路由为`/market`、`/funds/:thscode`。

本地API：GET `/api/market/indices`、`/api/market/indices/{thscode}`、`/api/market/events`、`/api/funds/{thscode}`、`/api/funds/{thscode}/nav`、`/api/funds/{thscode}/holdings`。应用参数模型限制对象、范围和能力，不透传任意参数/上游路径。

新能力在03的tools.py中加入白名单，继续用同一个任务/报告/证据契约；不另建板块Agent或基金Agent。未通过授权验证的模块可显示能力受限，不用样例填数。

真实验收按一只指数、一只基金、一页事件逐域验证。之前仅成功过一个指数快照，不代表目录、历史、成分、特色数据和基金已经可用。

## 3. 禁止事项与兼容性

不实现券商、基金交易、持仓管理、策略回测、抢涨停；不抓取研报/新闻全文。一般金融术语“交易日”“基金持仓”不等同交易功能，但对应服务不能产生资金副作用。

## 4. 验收标准

- [ ] 各资产类型分流正确，指数无复权、基金类别无混用。
- [ ] 当前成分、披露持仓、价格/净值语义和来源可检查。
- [ ] 事件解释区分供应商观点与AI推断，无交易信号。
- [ ] 新增 `tests/unit/market_data/test_index_contract.py`、`test_fund_contract.py`、`test_event_contract.py`、`tests/unit/analysis/test_fund_metrics.py`并通过。
- [ ] 分页/游标有终止与预算约束，不重复无限请求。
- [ ] 指数、基金、特色数据分别有受控真实验证结果或明确限制。
