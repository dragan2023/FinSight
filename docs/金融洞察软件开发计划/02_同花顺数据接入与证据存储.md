## 2. 任务详情

### 2.1 新建薄 REST 适配层

新增 `backend/app/market_data/models.py`、`hithink_client.py`、`service.py`、`cache.py`、`backend/app/research/evidence_repository.py`、`backend/app/api/market.py`。

httpx.AsyncClient 只访问官方 HTTPS origin；Key 只从服务端安全配置注入 X-api-key 请求头，TLS 校验开启，禁止自动重定向跨域泄露。只提供 search_instruments、get_snapshot、get_daily_bars、get_valuations、get_calendar 等固定方法，不向模型开放任意 URL/Header/path。

先判 HTTP 状态，再判 JSON code。兼容 HTTP429/code429、HTTP200/业务失败、无 request_id 和非 JSON 错误页。统一 DataError(category, safe_message, retryable, request_id?, retry_after?)；缺权限/参数错误不重复请求，网络/5xx/限流有界退避并尊重 Retry-After。

默认远端并发 1、连接超时 5 秒、读超时 20 秒、最多 3 次重试，总次数与等待均计入研究任务预算；这些是本产品初值，不是上游额度。应用启动和健康检查不请求全市场或检测所有数据域。

### 2.2 定义数据与证据唯一契约

| 对象 | 字段与语义 |
| --- | --- |
| Instrument | thscode、ticker、name、asset_type、exchange、currency；名称或六位代码先消歧 |
| SourceMeta | provider、endpoint、公开参数、source_time?、fetched_at、request_id?、adjust、report_period、schema_version |
| DatasetResult | data、evidence_id、source、quality、warnings、cache_hit |
| EvidenceRecord | id、kind、source、content_sha256、受限存储相对路径、行数、字段单位 |

quality 区分 complete/partial/empty/stale/unknown；调用失败是错误，不伪装 empty。允许 schema 多出字段，但必需字段缺失要报错。null 不补零，source_time 不用 fetched_at 冒充。日期统一保留毫秒戳并按 Asia/Shanghai 展示，未知时区明确标记。

成交量单位为股；`_pct` 是百分比点，例如 1.74 显示 1.74%，公式需要比值时显式转换。金融数值允许负数、超过100%和未知值；禁止建立只允许非负的通用 Money 类来承载财报。

同一搜索多个候选时返回名称、代码和类别供选择，不自选第一条；业务数据按资产类型路由，指数/基金不能送到股票估值接口。

缓存可以在服务内部使用简单有界 TTL/LRU，先检查标准库/现成实现，不造通用缓存平台。搜索24小时、快照60秒、估值15分钟、已结算日线24小时是初值；当前未收盘日线需短缓存并标注未结算。键包含标的、能力、区间、复权、报告期；合并在途相同请求。旧缓存只能显式标为 stale 展示。

不可变证据写入 `data/evidence/<uuid>.json`，临时文件原子替换并记录 hash；阶段 02 在 finsight.db 创建 evidence 表和版本迁移。后续报告表引用此证据，不另建一套索引。报告引用后不能因缓存刷新覆盖文件。大结果落盘，给模型只传摘要/有限行；前端通过 evidence_id 访问，不能指定本地文件路径。

### 2.3 API、前端数据卡与有界实测

新增 `frontend/src/api/market.ts`、`types/market.ts`、`components/InstrumentSearch.tsx`、`components/DataCard.tsx`。首页可搜索并手动查看真实数据；此时尚未实现 Agent，应明确标注。

| 本地端点 | 约束 |
| --- | --- |
| GET /api/market/instruments | q 必填，limit 1–20，多义候选不自动合并 |
| GET /api/market/snapshot | thscodes 显式必填，首版最多5只 |
| GET /api/market/history | 单股，日线，start/end 有界，首版最长3年，显式 adjust |
| GET /api/market/valuations | 最多5只 A 股，不提供历史估值分位 |
| GET /api/evidence/{id} | 返回来源与有限行预览，不暴露磁盘绝对路径 |

真实凭据从用户已提供的本机来源 `C:/Users/Administrator/Desktop/新建文本文档.txt` 导入 `.env` 或进程环境，只提取单个凭据、不执行正文、不复制 TXT 本身到项目、不输出 Key、不重复索取明文。如果原文件已不存在或格式不唯一，明确返回配置不可用，通过本机设置流程处理，不搜索其他无关凭据。启用 FINSIGHT_RUN_LIVE_API_TESTS 后才执行 requires_api 用例。

之前在旧工作区的探针已成功访问搜索、快照、日线、估值和指数；这些不是新项目验收。当前阶段用自己的客户端逐项重新验证；每次一只标的，不扫描全市场。利润表先前两次429，留给04专门处理，不作为02的阻塞条件。

## 3. 禁止事项与兼容性

不安装猜测名称的 SDK，不让 Python 后端启动 CLI 子进程；不接 AkShare/yfinance 回退，不提供模拟数据生产模式。不下载全市场 Parquet，不把未知源时间显示为“实时”。证据索引归 research 模块，供应商字段解析归 market_data，职责不混合。
