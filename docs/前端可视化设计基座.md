# 前端可视化设计基座

来源：[同花顺金融数据 API 文档站 · 16 个最佳实践](https://fuyao.aicubes.cn/best-practices/)（2026-09 抓取，预览图存于本机 `.cache/fuyao/`，不入库）。本文记录 FinSight 前端如何吸收这套实践的图表样式，以及后续扩展规范。

## 1. 设计原则（来自实践，结合本项目边界）

1. **版式即语义**：每个看板 = 眉题（模块英文名）+ 标题 + 口径说明 + KPI 卡组 + 图表面板 + 出处脚注。脚注必须写清口径、数据截至与局限（本项目“缺口可见”原则的落点）。
2. **A股语义色**：红涨绿跌，全站唯一；`up=#c9302c`、`down=#1f9d66`、平盘灰。方向色不允许出现第二套。
3. **模块强调色**：复盘/涨停线深红 `#d0483d`，热度紫 `#8b5cf6`，龙虎榜金 `#c9992e`，板块蓝 `#3d6fd8`，回测紫罗兰 `#7c5cd6`，公司陶土 `#c05a3c`。品牌绿 `#246653` 只用于界面框架。
4. **数据诚实**：null 不插值、不补零；缺口在图上留白、在脚注说明；接口没有的字段（如龙虎榜净额）不伪造对应图形。
5. **可检查性**：每张图附近保留明细表（MetricTable/Table），图是阅读入口，表是证据出口。

## 2. 设计令牌与基础设施（`src/components/charts/`）

| 文件 | 职责 |
| --- | --- |
| `tokens.ts` | 语义色、模块强调色、明暗两套 echarts 主题片段、`finNum/finPct/finYi` 数字格式化、`signColor/signTone` 涨跌语义 |
| `register.ts` | echarts 按需注册唯一入口（tree-shaking） |
| `EChart.tsx` | 统一容器：init/resize/dispose；无 canvas 环境（jsdom）优雅降级为空容器 |
| `series.ts` | `toNum` 宽松转数值、`sma` 含缺口移动平均（展示用，不落库） |
| `panels.tsx` | `ChartPanel`（眉题/标题/口径/工具条/脚注）、`KpiCards`、`RangeChips`、`ToneBadge`、`ScoreBar`、`Provenance` |
| `charts.css` | `.fin-*` 样式：面板、KPI 卡、梯队脉冲、日内区间条、暗色面板 |

## 4. 页面接入现状

- **公司页**：KPI 六卡（收盘/区间涨跌/MA/均额/回撤/距高点）→ 行情工作台（01）→ 趋势指标表；财务体检改为分维度 `ChartPanel`（02 版式）。
- **板块研究**：强度作战矩阵（09 象限）+ 热力带 + 共同窗口分流条；指数走势与成分涨跌分布面板化（03/12 版式）。
- **市场复盘**：KPI 卡（暗色）+ 涨跌停结构 tone 柱 + 连板梯队脉冲（04 暗色面板，●/○ 标注次日封板）+ 热度排名条（07）+ 上榜原因树图（12）+ 覆盖表；保留错误边界与类型守卫。
- **自选页**：异动监控台（05）：四 KPI + 可排序表（涨跌幅徽章、日内区间滑标、成交额、异动标签）。
- **全市场观察**：KPI tone 卡 + 涨跌分布 tone 柱 + 成交额前十排名条（06/07 版式）。
- **基金/研究/资料库**：经 `ResearchChart`（已升级到令牌）继承新样式。

## 5. 扩展规范

1. 新图表一律放 `charts/`，默认导出 + `React.memo`，option 用 `useMemo` 稳定引用；echarts 组件注册只改 `register.ts`。
2. 涉涨跌的数据必须走 `signColor/signTone/ToneBadge`，禁止硬编码颜色。
3. 每个面板必须给出 `footnote`（口径/截至/局限）或说明为何无需；表格与图同源同口径。
4. 接口没有的字段不画对应的图；先在本文档登记“数据就绪条件”，再实现。
5. 回测/策略类页面采用 13-15 控制台版式：管线 chips（步骤图标+箭头）→ 参数表单 → 运行按钮 → 指标分组网格（收益/风险/风险调整/稳定性）→ `EquityDrawdownChart` + 大数字解释卡。
