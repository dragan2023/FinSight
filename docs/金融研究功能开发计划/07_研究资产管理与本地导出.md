# 07 — 研究资产管理与本地导出

## 1. 摘要与前置阅读

优先级 P1；预计 2–3 批；直接依赖 01–04；目标：用户能长期阅读、查找、比较、补充、导出和删除自己的研究成果，缺口与证据限制不会在导出时被抹掉。05、06 的报告通过统一 schema 自动纳入，不作为本阶段前置条件。

前置阅读：现有 `backend/app/settings.py`、`storage.py`、`security.py`；02 的 `research/evidence_store.py`、`repository.py`；03 的 `research/models.py`、`reports.py`、`supplements.py` 和报告 UI；04 的附件与 storage_policy；现有 App、Layout、API 会话客户端。不要照搬旧计划中与当前报告 schema 不同的第二套资产结构。

## 2. 任务详情

### 2.1 报告库、版本与笔记

新增 `backend/app/research/library.py`、`notes.py`、`retention.py`；扩展 repository 和 SQLite，按报告时间、问题、标的、类型、用户标签、覆盖程度检索。首版使用 SQLite 参数化查询和必要索引，不为有限本地资料增加向量库或独立搜索服务。

报告正文、输入范围、来源、计算与缺口随版本不可变；标签、收藏和用户笔记可编辑，但记录它们不是原报告模型结论。报告打开默认读本地保存内容，数据变旧显示旧日期，不后台取最新数据替换当时事实。

版本对比优先比较 evidence/metric/gap/用户假设的增删改，再展示章节文字差异；不能把 LLM 换措辞称重大投资变化。部分失败的新版本也可在版本树看到，旧版不被覆盖，用户可选择保留或删除失败草稿。

### 2.2 本地导出契约

新增 `backend/app/research/exporting.py`、`export_templates.py`。首版支持 Markdown、静态 HTML、结构化 JSON、指标 CSV；不引入 Office/浏览器服务或付费导出 API。HTML 提供打印样式供用户通过系统浏览器打印为 PDF，不承诺后台自动生成 PDF。

每份报告导出至少包含问题/范围、模型和生成日期、实际数据日期、事实/推断区分、指标口径、报告覆盖程度、未完成章节、缺口、来源引用、局限和版本号。JSON 带 schema_version，CSV 带标的/期间/单位/来源引用列；报告不完整也允许导出，但不能隐藏 partial/truncated/unstructured 标识。

默认只导出用户所选报告和许可允许的指标/出处，不打包数据库、原始附件、全部证据目录、Key、环境变量、绝对本地路径、隐藏推理或 SDK 调试内容。用户显式选择证据附件时逐项检查 storage_policy/导出权，不能因本地可读就自动可分享；不允许导出的材料只保留允许的引用和受限说明。

| 格式 | 安全与可读性 |
| --- | --- |
| Markdown | 过滤危险 URL/HTML，不自动嵌入远端图片或追踪资源，保留源链接 |
| HTML | 模板统一 escape，禁止脚本/事件属性/iframe，CSP 限制外部加载；图表可用静态表格替代，完全离线可读 |
| JSON | 严格有限数值与版本 schema，使用明确 Decimal 字符串/单位，不混入未验证章节对象 |
| CSV | 标准 CSV quoting；对用户/模型可控文本的公式触发字符及前导控制字符做中和，不只用双引号包住；经 schema 确认的数值列保持数值语义 |

原始格式失败文本只放独立、明确标为未验证的文本附件或区域，不假装正规结构化报告；文件名用报告 ID/安全标题生成，下载通过服务端 ID 查找而不是任意路径。

### 2.3 保留与删除由用户决定

设置页的“数据使用与本地存储”显示报告、证据、附件和临时文件占用量与默认保留行为。用户可清理未引用附件、失败任务临时文件和过期缓存，删除前看到影响范围；不在启动时自动清空研究资料。

普通删除先检查是否被报告引用，给出“只删原始附件，保留允许的报告及出处”或“连同选定报告一起删除”的具体结果，由用户决定。保留报告但删除原文时显示证据已删除/不可完整复核；删除不将该出处改成另一个链接或另一个期间数据。不能通过路径拼接递归删除任何项目外目录。

报告删除只影响被选版本及没有其他引用的资料，保留仍被其他报告引用的证据；引用关系使用外键和事务校验。文件删除失败记录可重试的本地清理错误，不让数据库显示已经清理成功。清理结束释放任务临时内容；缓存与已授权报告的生命周期分开。

API Key 的删除/更换仍走 01 配置服务，不随报告清理误删根密钥；同样不把删除模型配置当删除全部旧研究。凭据/根密钥备份只在安全说明中提示用户私下保存，不加入普通报告导出或分享包。

### 2.4 页面和 API

新增 `backend/app/api/library.py`、`api/exports.py`；新增 `frontend/src/api/library.ts`、`api/exports.ts`，`pages/Library/index.tsx`、`components/ReportVersionDiff/index.tsx`、`components/ExportDialog/index.tsx`；修改 App/Layout 并扩展设置存储分区。

| 端点 | 行为 |
| --- | --- |
| GET `/api/library/reports` | 分页/筛选本地报告 |
| GET `/api/library/reports/{id}/versions` | 读取同研究链版本 |
| POST/PUT `/api/library/notes`、`/{id}` | 创建/修改独立用户笔记，不修改报告正文 |
| POST `/api/exports` | 校验所选报告与许可，生成到 `data/exports/` 后返回 export_id |
| GET `/api/exports/{id}/download` | 校验会话后下载既有文件，不重新生成 |
| POST `/api/library/deletion-preview` | 仅返回删除影响，不改变数据 |
| POST `/api/library/delete` | 用户确认具体 ID 列表后执行有引用检查的删除 |

用户可以在库中直接返回 03 的补充/再分析流程，沿用模型与 API 配置。导出、笔记、标签、版本对比和删除预览全部本地完成，不能隐式调用 LLM“润色”或向第三方上传成果。

## 3. 禁止事项与兼容性

不提供未经授权的全文再分发，不默认公开分享，不生成第三方云盘/站点链接。不将 Key 或用户私人资料夹带在导出中，不为版本管理复制整个数据库。没有原文访问权时明确局限，不能改写证据让报告看起来完全可复现。现有报告 schema 的扩展必须保持旧版读取兼容。
