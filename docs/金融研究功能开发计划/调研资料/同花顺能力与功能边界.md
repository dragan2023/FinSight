# 同花顺能力与功能边界

## 1. 来源与适用范围

2026-08-31 核对 [Financial-API](https://github.com/HiThink-Tech/Financial-API)、[REST 契约](https://github.com/HiThink-Tech/Financial-API/tree/main/docs/api) 与[在线聚合文档](https://fuyao.aicubes.cn/llms-full.txt)。本轮为文档调研；旧计划中的有限账号探针仅作历史记录，不是当前客户端联调结果，也不证明财务/基金授权。

## 2. 功能映射

| 功能 | 主要接口组 | 可交付结果与限制 |
| --- | --- | --- |
| 财务体检 | financials 三表与 indicators | 增长、现金质量、费用/杠杆变化；不是完整财报或附注审计 |
| 同行比较 | valuations/snapshot、financials、指数当前成分 | 用户指定比较组；当前估值与同报告期财务，不自动生成行业排名 |
| 投资理由跟踪 | 前述接口 + 本地历史报告 | 已保存假设及证据变化，不是买卖指令 |
| 相对表现 | 个股与指数 prices/historical | 同时段走势/回撤；当前成员回看需标明样本偏差 |
| 基金穿透 | portfolio/holdings、stock-history、industry/asset-allocation | 披露持仓重叠和风格变化，不宣称实时完整组合 |
| 基金质量 | performance/nav、returns、drawdowns、managers | 同窗口风险收益与经理任期对齐，不将基金所有历史归功于现任经理 |
| 相关市场复盘 | special-data 池、热榜、龙虎榜、当日异动 | 事实/供应商解释/待核实分开，不将热度当收益预测 |

## 3. 必须保留的限制

### 3.1 股票、财务与估值

按详细行情契约实现日线；官网概览中“日/周/月”的泛化描述不能覆盖具体参数约束。当前快照的 source timestamp 可能为空；源时间与获取时间分开。`total_debt` 指负债合计，不是有息债务；经营现金流减购建长期资产支出只能叫简化现金余量，不直接冒充完整 FCFF/FCFE。财报按报告期和披露日对齐，单季/累计未知则跳过相应计算而继续其他分析。[价格](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-prices.md)、[财务](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-financials.md)

在线财务指标列出毛利率、ROE、扣非加权 ROE、周转率和偿债指标；abilities 是数组、value 为字符串或 null。百分比原值、比率、倍数必须按指标字典解析。[财务指标](https://fuyao.aicubes.cn/docs/api-reference/financial-indicators/)

股票估值仅当前五项，不能生成十年历史分位。顶层 timestamp 是返回指标中的最新有效时间，不代表各项同时更新。[估值](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-valuations.md)

### 3.2 指数、基金与事件

当前成分股没有历史调整序列与权重。官网股票基础、个股反查所属板块、指数概况仍标规划中，不能作为现成功能；可从用户选定板块的当前成分构建有限映射，不在启动时遍历全市场。[指数契约](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-index.md)、[规划中的指数概况](https://fuyao.aicubes.cn/docs/api-reference/index-overview/)

基金单位净值与复权净值不同；复权净值又不等于累计净值。历史持仓必须先发现 report_type/end_date，跨期权重变化不直接等于经理买卖。场内快照可覆盖 ETF/LOF，历史行情仅 ETF，不能泛化。[基金持仓](https://fuyao.aicubes.cn/docs/api-reference/fund-portfolio/)、[基金契约](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-fund.md)

基金历史指标中的 `track_index_pe_ttm_five_year_percentile` 是跟踪指数 PE TTM 五年分位，仅在返回有效值的产品展示；不等于基金净值分位，也不能反推任意股票估值。没有 IOPV 不能算实时折溢价。[基金业绩与回撤](https://fuyao.aicubes.cn/docs/api-reference/fund-performance/)

连板天梯每梯队最多展示四只，不能统计全市场数量。龙虎榜单日/三日榜不得混加；异动解释仅当日，不支持历史回查。竞价量单位为手，而股票普通行情为股；时间戳含义因端点而异。[特色数据](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-special-data.md)、[竞价](https://github.com/HiThink-Tech/Financial-API/blob/main/docs/api/endpoints-auction.md)

### 3.3 公开能力和授权

公开能力不覆盖分钟/tick/Level-2、海外行情、宏观库、通用新闻公告全文和研报全文。基金资讯返回元数据与 URL，不等于全文服务。公开源代码许可证不等于金融数据再分发与外部模型处理权。账号权限和服务稳定性仍需实际小范围验证。[公开能力边界](https://github.com/HiThink-Tech/Financial-API#当前公开能力边界)
