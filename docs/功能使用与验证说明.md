# FinSight 功能使用与验证说明

## 1. 使用前提

1. 在项目根目录创建并使用 `.venv`，安装 `requirements.lock.txt`。
2. 在 `frontend/` 执行 `npm ci`。
3. 双击 `启动FinSight.bat`；应用仅绑定 `127.0.0.1` / `localhost`，不能用于公网或多人共享。
4. 首次保存模型或数据服务 Key 时，设置页在本机初始化加密根密钥。请私下备份 `.env`；根密钥丢失后既有密文无法恢复。

## 2. 设置模型与数据源

1. 打开“模型与 API 配置”，新增并激活自己的模型配置。未配置模型时，研究工作台仍可展示已保存的本地数据和条件框架。
2. 为同花顺、Tushare、博查或 Tavily 分别保存自己的 Key。保存 Key 不等于测试成功；每个能力必须手动测试。
3. 删除、禁用或更换凭据后，后续请求不会回退到环境变量或开发者 Key。已经发出的上游请求可能已产生费用。
4. 真实测试可能计费。仅在确认账户、权限和单次范围后操作；测试结果应区分通过、未配置、无权限、额度限制和协议不兼容。

## 3. 基础研究与补充

1. 先在“研究概览”确认标的，再在“研究工作台”提交问题。任务会显示模型、数据源和调用预算。
2. 任务完成后查看证据、确定性指标、章节覆盖程度、限制和缺口。`partial`、`truncated`、`unstructured` 均不代表完整正式结论。
3. 补充文字或附件只保存到本机，默认不自动外发，也不会自动重分析；选择补充资料后点击“再分析”才会新建版本。
4. 公司体检只读取已保存证据；它不会刷新行情或发起模型调用。行业不适用指标与“尚无数据”会分别显示。
5. 关注与理由只保存研究标的和用户确认的理由，绝不保存持仓、不做后台监控或交易通知。理由复核必须带报告证据或指标引用。

## 4. 板块、基金与市场复盘

1. 板块相对表现、板块广度、基金披露持仓重叠、净值质量和市场复盘计算均只处理用户明确选定的数据范围；没有共同交易日、同一披露期或可确认权重口径时，结果会显示限制而非补齐数据。
2. 基金持仓重叠是已披露证券的可见下限，不是实时持仓或账户配置；净值使用单位净值或复权净值的差异会随结果标示。
3. 龙虎榜和连板资料只用于可核对的市场事实；不同统计窗口不会相加，历史日期没有可用异动解释时会明确显示不支持。
4. 本阶段的计算接口只在本机执行，外部数据刷新仍须由用户在设置页确认数据能力、权限与范围后显式发起；不会后台轮询或自动调用外部服务。

### 4.1 推荐操作顺序

1. 在“板块研究”粘贴或选择已确认的价格序列，选择 1 个参考指数和 1–3 个比较对象。页面只采用共同交易日，归一化起点为 100；没有共同窗口时不会生成收益差。
2. 在“基金研究”先确认基金类型、实际披露期和权重口径，再比较 2–10 只基金。只有同一披露期且权重定义明确时才显示可见重叠下限；其余情形只保留共同证券与限制。
3. 在“市场复盘”输入或读取已授权的当日材料。龙虎榜的一日/三日窗口、涨停梯队和异动解释会分开显示；历史日期没有对应解释时不移植今日叙述。

## 5. 报告库、导出和删除

1. “研究资产库”检索的是本地报告，打开或筛选不会调用外部 API。
2. 报告完成后可在“继续追问”中围绕该报告提问。助手使用报告和本机对话记忆回答；只有勾选“本次允许联网搜索”时才会向已配置的博查（或 API 调用中选定的 Tavily）发送搜索关键词。搜索结果是补充线索，不覆盖报告中已保存的事实口径。
3. 支持可读报告 Markdown、HTML、JSON、CSV 导出。HTML 可由系统浏览器打印为 PDF；应用不会后台生成 PDF。可读报告不默认打印引用 ID 或后台处理过程。
4. “核验材料（MD）”是单独下载项，不在前端报告正文中展示。它包含已保存的结构化记录、脱敏后的同花顺等上游原始响应、内容哈希和报告追问中保存的搜索标题/链接/摘要，供人工校验。历史证据若产生于该功能启用前，则只含当时已保存的结构化记录和哈希。
5. 所有导出都不包含 API Key、环境变量、隐藏推理、原始附件、完整数据库或未保存的网页全文。
6. CSV 会中和以 `= + - @` 开头的文本，HTML 会转义内容并施加离线 CSP。不要把受限来源全文当作可自由再分发的内容。
7. 删除报告前会显示附件、摘录、笔记和导出文件的影响范围；必须再次确认。仍被投资理由观察或其他版本补充引用的报告会被拒绝删除，避免破坏历史可复核性。
8. 报告正文、计算、证据和缺口随版本固定不变；点击“标签”可维护本地组织标签，不会改写报告结论。笔记与标签属于用户注释，不是模型观点。

## 6. 验证命令

```powershell
.\.venv\Scripts\python.exe -m pip check
.\scripts\test_backend.ps1
cd frontend
npm run lint
npm run test
npm run build
```

测试使用离线夹具；真实 API/模型联调只在用户明确启用对应标志、提供自己的 Key 并授权范围后执行。测试不应打印或上传 Key、reasoning 内容或真实数据库。不要直接执行不带 `--basetemp` 的 pytest 命令；`scripts/test_backend.ps1` 会把临时文件限制在项目 `.cache/pytest/`。

## 7. 故障恢复

- 无数据、权限不足、限流、字段无法解释或模型输出不通过校验时，查看缺口和限制后补资料、调整范围或稍后重新发起。
- 刷新或断线后，研究页面从同一任务事件序列继续读取；不会重发生成请求。
- 进程重启会将进行中的任务标为中断，不会自动重放可能计费的请求；已保存报告仍可读取。
- 本机应用不是多用户 SaaS。不得用隧道、反向代理或 `0.0.0.0` 将其公开。
