> **项目决策**：FinSight 统一使用同花顺金融数据 API（https://fuyao.aicubes.cn）作为行情、财务、估值、指数、基金、特色数据的**唯一权威数据源**。

> 手册全文：本目录 `llms-full.txt`（276,744 字节，SHA-256 前缀 de404f225ce74198，2026-09-03 抓取核验）；索引：`llms.txt`；在线版：https://fuyao.aicubes.cn/docs 。

## 1. 接入基础

- Base URL：`https://fuyao.aicubes.cn`。REST 鉴权：请求头 `X-api-key: <key>`（管理页 /admin 签发，Key 只在创建弹窗可见一次）。
- MCP 鉴权：自托管/本地用环境变量 `API_KEY`；托管网关同样校验 `X-api-key`。
- **所有接口（含错误）恒返回 HTTP 200**，业务结果走统一信封 `ApiResponse{code, message, request_id, data}`；`data` 含 `timestamp`（毫秒）与 `item[]`（部分接口另有 total/pagination）。
- 时间戳一律**毫秒 Unix、时区 Asia/Shanghai**；价格原币（A 股恒 CNY）；字段 snake_case；**百分数字段一律「百分数原值」**（8.88 = 8.88%）；`null` = 该期/该字段未披露，**透传不补零**。
- 标的一律**完整 thscode**（`600519.SH`/`000858.SZ`/`430047.BJ`/`510300.SH`/`025480.OF`/`886042.TI`），**不接受纯 ticker**；单标的接口（复权、财务三表、指数 K 线、热榜走势、ETF 行情）**不接受逗号**。

### 错误码全表（13 个）

| code | 含义 | 典型场景 |
|---|---|---|
| 0 | 成功 | 有快照但无匹配时也返回 0 + `item: []` |
| 1001 | 缺少必填参数 | start/end/q/thscode/fund_type 漏传 |
| 1002 | 参数格式错误 | thscode 含逗号、日期格式错、枚举非法、空 token |
| 1003 | 取值越界 | limit 越界、窗口超上限（K 线 10 年 / 基金 5 年 / 热榜龙虎榜 1 年）、估值超 100 token |
| 1004 | 参数冲突 | financials 同时传 start/end 与 limit；只传 start 或只传 end；热榜 start_date > end_date |
| 2001 | 未认证 | X-api-key 缺失或无效 |
| 2003 | 权限不足 | Key 无该 capability 权限 |
| 3001 | 标的不存在 | 不在代码表 |
| 3002 | 数据未就绪 | 标的存在但暂无数据 |
| 3004 | 标的类型不支持 | 如对 LOF/场外/REITs 调 ETF 行情 |
| 4001 | 频率超限 | 超约定 QPS |
| 5001 | 服务内部错误 | 服务端未知错误 |
| 5002 | 上游超时 | 数据源超时（财务指标=Arsenal，估值=DataAPI） |
| 5003 | 数据源不可用 | 上游异常/非 0 状态 |

## 2. A 股行情 prices

| 端点 | 关键参数 | 返回/坑 |
|---|---|---|
| `GET /api/a-share/prices/snapshot` | `thscodes`（逗号分隔，可选）；省略时全市场按代码表升序 + `limit`(默认100)/`offset` 分页 | 显式传 thscodes 时**忽略分页**按入参顺序返回；**响应不含中文名 name**，展示名必须走 meta 检索/列表；字段：last_price、price_change、price_change_ratio_pct、open/high/low/prev_price、volume(股)、turnover |
| `GET /api/a-share/prices/historical` | `thscode`（单只，禁逗号）、`interval`(仅1d)、`start`/`end`(毫秒, 必填, 窗口≤10年)、`adjust`(none/forward/backward, **默认forward**)、`offset` | 缺 start/end → 1001；窗口超 10 年 → 1003；返回 date_ms + OHLC + volume + turnover |

## 3. 全市场导出 market-dumps（全市场观察页同步的数据源）

- 3 种 dump（Parquet，全部**未复权** CNY）：

| dump | dump_id | 模式 | 下载端点（API） |
|---|---|---|---|
| 10 年全量日 K | `a_share_daily_k_1d_none_10y` | FULL years=10 | `GET /api/dump/market-dumps/daily-k/download-url` |
| 最近 10 交易日日 K | `a_share_daily_k_1d_none_10d` | RECENT_TRADING_DAYS=10 | `GET /api/dump/market-dumps/daily-k-10d/download-url` |
| 复权因子全量 | `a_share_adjustment_factors_event_none_all` | FULL | `GET /api/dump/market-dumps/adjustment-factors/download-url` |

- 浏览器按钮走 `/dump/**`（登录 Cookie），API 客户端走 `/api/dump/**` + X-api-key。
- **预签名 S3 链接约 5 分钟过期，严禁持久化/缓存**——每次下载前现取（FinSight「同步状态 failed」优先排查此处）。
- 日 K schema 主键 `(thscode, date_ms)`：interval 固定 `1d`、adjusted 固定 `none`、OHLC/volume/turnover、currency=CNY。
- 复权因子 schema 主键 `(thscode, ex_date_ms)`：dividend_per_share(税前)、per_share_bonus、allotment_ratio、allotment_price。
- 官方提供 `read_market_dump.py`（pyarrow）校验脚本：--ticker 过滤、--from-date/--to-date 导出 CSV、--check-duplicates 查重。

## 4. 标的元信息 meta（中文名与消歧的唯一来源）

| 端点 | 关键参数 | 返回/坑 |
|---|---|---|
| `GET /api/meta/tickers/search` | `q`(必填, thscode/ticker/中英文名, 子串匹配)、`exchange`(SH/SZ/BJ, 场外基金不过滤)、`asset_type`、`limit`(≤50, 默认10) | asset_type 枚举：a-share / a-share-index / fund-otc / fund-etf / fund-lof；非法值 1003 |

## 5. 除复权 corporate-actions（复权因子唯一权威）

- `GET /api/a-share/corporate-actions/adjustment-factors?thscode=&from=&to=`（日期 YYYY-MM-DD）。
- 返回**原始事件流**，按 ex_date_ms 降序；item 字段仅 `ticker / ex_date_ms / dividend_per_share(税前) / per_share_bonus`。
- **不返回 event_type / record_date / adjust_factor**：事件类型由两数值隐式区分（纯送股=dividend 0，纯分红=bonus 0）；**复权因子由客户端自行推导**；要现成复权价直接调 prices/historical?adjust=forward|backward。

## 6. 财务三表 financials（公司体检页数据源）

- 端点：`/api/a-share/financials/income-statements` / `balance-sheets` / `cash-flow-statements`，三者入参契约完全一致。
- 参数：`thscode`(必填,含后缀,禁逗号)、`period`(必填: `annual`=仅Q4 / `quarterly`=每季度末, 默认 annual)、取数模式二选一：
  - 最近 N 期：不传 start/end，`limit` 1..20 默认 4，按 period_end 降序；
  - 时间区间：同时传 `start`+`end`（毫秒戳，闭区间，≤10 年）；
  - **与 limit 同传、或只传 start/end 之一（半开区间）→ 1004**。
- 共有元数据：fiscal_year、fiscal_period(FY/Q1..Q4)、report_date_ms(披露日)、period_end_ms(报告期末)、currency；金额原币元、basic_eps 元/股。
- 利润表字段：operating_income、operating_costs、operating_expenses、sales_fee、manage_fee、research_and_development_expenses、operating_profit、interest_expenses、profit_total、income_tax_expense、net_profit、parent_holder_net_profit、basic_eps。
- 资产负债表字段：assets_total、total_current_assets、non_current_nets_total、cash、accounts_receivable、total_debt（**负债合计口径，非有息负债**）、holder_equity_total。
- 现金流量表字段：act_cash_flow_net、invest_cash_flow_net、financing_cash_flow_net、pay_fixed_assets_etc_cash、pay_dividends_profits_interest_cash、cash_equivalents_net_addition。

## 7. 财务指标 financial-indicators（一次五类）

- `GET /api/a-share/financials/indicators?thscode=&report=yyyy-1..4`（1一季报/2中报/3三季报/4年报，格式非法 1002）。
- 返回 `abilities[]` **固定顺序** growth → profitability → solvency → operation → cash-flow；每块 `indicators[]{index_id, value}`。
- **value 为 string|null**（保留上游原始精度，不转 number）；百分比按百分数值（89.12=89.12%）、周转率按次、倍数按倍。
- 24 个 index_id 全集：growth=total_assets_growth_ratio、net_profit_yoy_growth_ratio、operating_income_yoy_growth_ratio、operating_profit_yoy_growth_ratio；profitability=sale_gross_margin、sale_net_interest_ratio、total_assets_net_ratio、index_deduct_weighted_avg_roe、index_weighted_avg_roe；solvency=current_ratio、quick_ratio、assets_debt_ratio、cash_ratio、earned_interest_multiple；operation=long_term_debt_equity_ratio、total_assets_turnover_ratio、inventory_turnover_ratio、current_assets_turnover_ratio、receive_account_turnover_ratio；cash-flow=cash_operating_index、operating_cash_flow_net_divide_income、net_profit_cash_content、operating_cash_net_yoy_growth_ratio、cash_meet_invest_ratio。

## 8. 交易日历 calendar

- `GET /api/a-share/calendar/trading-days`：**无入参**，固定窗口 [今日-1年, 今日]；item[]{date_ms, date(yyyyMMdd)} 升序。

## 13. 估值 valuations（同行比较页 PE/PB 数据源）

- `GET /api/a-share/valuations/snapshot?thscodes=`（**必填**，逗号分隔，每项=6位数字+.SH/.SZ/.BJ；服务端 trim+大写+去重保序；**一次默认最多 100 token，不可配置**）。
- 固定返回 5 指标：`pe_ttm / pe_mrq / pb_mrq / ps_ttm / pcf_ttm`（number|null）；**负值与高精度小数原样返回**，不取绝对值不舍入；上游未返回的股票**不生成占位项**；无匹配 → code=0 + total=0 + item=[]。
- 口径：TTM=最近连续 12 个月；MRQ=最近报告期。**不提供历史估值、分页、指标选择或高低估结论**；data.timestamp 是所用上游元数据最大有效时间，不代表各指标同步更新。
- 使用告诫（原文要点）：净利润为负时 PE 无效或为负，不宜「越低越低估」；净资产为负时 PB 失义；PCF 在现金流为负/波动大时可能为负或空；跨行业直接比较可能有偏；TTM 与 MRQ 口径差异可能明显。

## 16. FinSight 页面 ↔ 端点对照与统一规则

| FinSight 页面 | 应使用的权威端点 |
