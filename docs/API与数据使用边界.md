## 1. 本机 BYOK 边界

FinSight 是单机、回环地址的个人研究应用。每个安装实例仅使用该用户在设置页主动保存的 Key；服务端不会向浏览器、日志、报告、导出文件或 URL 回传 Key。它不是账号系统、云端密钥托管或多租户隔离方案。

## 2. 数据来源注册表与可信级别

FinSight 从五类来源取数，统一登记在数据来源注册表（backend/app/sources/registry.py），概览页「数据来源」区可查看当前启用状态：

| 来源 | 定位 | 可信级别 | 费用 |
|---|---|---|---|
| 同花顺金融数据 API（ths） | 唯一权威行情、财务、估值、指数、基金、特色数据源 | 权威依据 | 免费，取数需用户主动操作 |
| 本地全市场仓库（warehouse） | 同花顺官方导出落库 DuckDB（未复权日 K 等），供基率统计与本地研究型回测 | 权威依据（本地副本，随同步更新） | 免费，同步下载需用户确认 |
| 博查搜索 API（web_search） | 付费官方搜索 API 的解释线索与外部信息发现，仅使用 API 返回的标题、摘要与链接 | 线索，需交叉验证 | 付费，仅用户触发 |
| 金融媒体 RSS（rss） | 媒体公开订阅端的新闻线索（仅订阅读取，不是爬虫） | 线索，需交叉验证 | 免费 |
| 私有知识库（kb） | 用户上传文档的分块检索与引用回链 | 可核验佐证 | 免费，本地检索；后续可选嵌入服务另行付费 |

- 可信级别含义：**权威依据**＝可直接作为事实引用；**可核验佐证**＝可用作依据，但必须给出原文或数据批次定位；**线索**＝未经第二来源或工具数据交叉验证不得作为结论依据，交叉验证通过后升级为「已交叉验证」。
- 同花顺金融数据 API 的接口契约以 `docs/同花顺官方手册/` 为唯一权威依据（`契约要点速查.md` 为 16 节完整速查，`llms-full.txt` 为 97 页官方全文聚合）；字段名、取数模式、分页上限、口径与错误码一律先查该目录或项目记忆，不得凭记忆编写，也不得用其他数据源、东财或搜索摘要替代或补齐其字段。
- 全市场下载仅在用户确认同步后发生。短期下载链接、请求头和 API Key 不写入 SQLite、证据、日志或前端状态；DuckDB 仅保存可重新下载的市场事实与派生数据，用户配置、证据和报告仍保存在 SQLite。基金资讯 URL 不是正文提取授权。
- 为支持用户的人工校验，授权数据请求的脱敏原始响应会在本机证据库中保存，并且只进入用户主动下载的「核验材料（MD）」。它不包含 Key、不在页面默认展示，也不会自动上传或共享。
- 模型负责组织与解释；数值指标由程序计算。事实、推断、用户假设、来源和缺口必须分开。null 不补零；不混口径（单季/累计、复权净值/累计净值、当前成分/历史成分）；金额原币元；时间戳毫秒（Asia/Shanghai）；百分数为原值（8.88=8.88%）。
- 报告图表只使用后端按已保存指标生成的受限 chart spec；不接受模型提供的 ECharts option、HTML、JavaScript、SQL、URL 或原始数据数组。

## 3. 受控允许（v2 起解禁，附实现约束）

1. **结构化投资建议**：投资建议 Agent 是核心输出（方向/标的/条件/概率/风险/失效条件）。每条建议登记进本机建议台账，可跟踪、可复盘、可注销；界面常驻「研究参考，不构成投资建议」。概率必须标注来源（历史同类案例统计 / 主观估计），两者不得混写。
2. **研究型筛选**：允许多条件横截面筛选 + 证据链。筛选条件与结果全程落证据库；结果一律标注为「候选池」，不是「买入清单」。
3. **情景化参考区间与仓位思考框架**：必须展示计算假设与敏感性；标注教育用途；禁止个性化持牌建议表述；输出区间、分布或档位，不输出点值承诺。
4. **本地研究型策略实验与影子验证**：仅对已确认单标的运行固定规则、前复权日 K 和明确单边成本的历史实验；结果必须展示样本、成本、基准、回撤与局限，不能宣传为已验证收益。顾问台账的预测事件只在登记后自然到期时、由用户主动结算；不连接账户、不模拟成交、不自动交易。
5. **新闻订阅三通道**（本产品自身不实施任何爬取，只做订阅端读取）：
   - **同花顺官方资讯接口**（权威；经官方 README 核实免费开放，仅约定限流，无计费条款）：基金资讯文章（`/api/fund/news/article-list`）与个股异动原因解读（`/api/a-share/special-data/anomaly-analysis-*`），按官方 API 契约接入。
   - **媒体官方 RSS/Atom 端点**（免费、推荐）：只访问用户显式添加的媒体官方订阅端点；RSS 订阅不是爬虫——不自动发现源、不跟随页面链接、不抓取网页正文。
   - **第三方聚合端点**（免费、用户自担）：用户显式添加的第三方聚合服务端点（如公共 RSSHub 实例路由）输出的 RSS/Atom。上游由第三方抓取，本产品与其无直接关系，但内容的上游授权链条风险与端点可用性风险由用户知悉并自担；**推荐优先使用官方端点**。
   三通道统一约束：只存标题、摘要（≤500 字）与链接，全文不入库；展示注明来源与原文链接；新闻内容交叉验证前只是线索。仅当用户显式开启后，后台才轮询已订阅的免费端点，默认关闭；付费 API 仍必须用户触发。
6. **情绪与资金面证据输入**：热榜、龙虎榜、涨跌停等特色数据可作为建议的证据输入；证据按「事实/情绪/资金/推断」分层面标注，推断层必须给出反例与失效条件；涨停不等于可交易。
7. **私有知识库**（本地文档检索与引用回链）：用户上传的本地文档（PDF/Markdown/TXT/CSV/TSV/XLSX）仅在本机解析、分块与存储，全文与分块只落本地库。未启用嵌入时检索完全在本地 FTS5 关键词索引上完成，文档内容零外发；用户主动接入嵌入服务（Qwen 文本向量化）后，仅在用户主动摄取或检索时把相应分块文本/查询词发往该服务用于向量化，此外不做任何外发。检索命中是可核验佐证：展示摘录、文档名与原文定位（标题/页码/行号），Agent 引用必须回链。文档删除级联清除全部分块与索引；重建索引在本机基于已存全文重新执行。
8. **顾问工作台**（V2-04，多轮建议 Agent）：单条建议默认 ≤14 次模型请求（用户主动发送触发，绝不后台轮询）；联网搜索为付费服务，必须用户在当次对话显式勾选；禁语词表程序校验（承诺性/绝对化措辞触发一次修复，仍违规则拒发）；证据不足输出「暂不表态」而非编造方向；建议台账只存建议卡快照、参数哈希与结算结果，结算按用户点击执行，不自动交易、不外发通知；界面常驻「研究参考，不构成投资建议」。

## 4. 保留红线（不放松）

1. 不接入真实订单、券商账户、自动交易、自动下单；不外发任何通知。
2. 不承诺收益、不保证成功率；所有建议与观点必须携带「研究参考，不构成投资建议」与相应风险提示。
3. 不伪造证据：正文关键数值必须绑定证据 ID；无证据的表述必须标注为一般性知识或假设；搜索与 RSS 内容在交叉验证前只是线索。
4. **不使用爬虫等灰色技术**：本产品不内置、不运行爬虫、无头浏览器或任何自建抓页技术；网页信息只经由用户配置的付费官方搜索 API（博查，仅其返回的标题/摘要/链接）进入系统；新闻信息只经由第 3 节第 5 条的三通道进入系统。自建聚合抓取实例视同自行爬取，属红线禁止；使用第三方聚合端点不改变「本产品不爬取」的性质，但上游授权风险由用户自担。
5. API Key、预签名 URL、模型隐藏推理不落盘不外传；付费 API 不自动调用——付费调用只能发生在用户主动发起的会话或任务中，绝不后台定时触发（免费 RSS 订阅轮询是唯一例外）。
6. 不提供个性化持牌投顾表述；算法与仓位输出统一标注「研究参考，不构成投资建议」。
## 5. 外部调用授权

普通启动、健康检查、报告库读取、导出、笔记、关注清单和公司本地体检均不调用外部服务。模型试用、能力测试、取数、搜索和再分析均需用户主动操作；用户显式开启的免费 RSS 订阅轮询是唯一例外，且仅限已订阅的免费公开源。模型与来源的费用、限流和许可由用户自行确认。

## 6. 公网服务不在本次范围

在没有登录、用户级所有权校验、服务端密钥治理、审计、备份、限额、文件沙箱、出网控制及适用数据许可之前，不得将此应用公开部署或宣传为 SaaS。BYOK 不自动解决第三方数据或模型处理许可。
