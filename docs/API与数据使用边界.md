# API 与数据使用边界

## 1. 本机 BYOK 边界

FinSight 是单机、回环地址的个人研究应用。每个安装实例仅使用该用户在设置页主动保存的 Key；服务端不会向浏览器、日志、报告、导出文件或 URL 回传 Key。它不是账号系统、云端密钥托管或多租户隔离方案。

## 2. 数据与模型边界

- 同花顺和 Tushare 数据的可用范围取决于用户账号权限与许可；HTTP 成功不等于字段完整、商用许可成立或数据适合模型处理。
- 博查/Tavily 搜索是解释线索，不取代财务报表；只在用户对当次报告追问明确授权后调用。报告正文不展示搜索材料；“核验材料（MD）”仅导出该次已保存的标题、链接和摘要，不能当作网页全文再分发。
- 为支持用户的人工校验，授权数据请求的脱敏原始响应会在本机证据库中保存，并且只进入用户主动下载的“核验材料（MD）”。它不包含 Key、不在页面默认展示，也不会自动上传或共享。
- 模型负责组织与解释；数值指标由程序计算。事实、推断、用户假设、来源和缺口必须分开。
- 系统不提供订单、账户、回测、选股、目标价、仓位建议或自动通知。

## 3. 外部调用授权

普通启动、健康检查、报告库读取、导出、笔记、关注清单和公司本地体检均不调用外部服务。模型试用、能力测试、取数、搜索、正文提取和再分析均需用户主动操作；模型与来源的费用、限流和许可由用户自行确认。

## 4. 公网服务不在本次范围

在没有登录、用户级所有权校验、服务端密钥治理、审计、备份、限额、文件沙箱、出网控制及适用数据许可之前，不得将此应用公开部署或宣传为 SaaS。BYOK 不自动解决第三方数据或模型处理许可。
