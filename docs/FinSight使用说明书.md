# FinSight 使用说明书

> 面向软件使用者的操作手册。不讲代码、不讲部署原理，只讲：这个软件能做什么、每个页面怎么用、看到提示该怎么处理。
>
> 配套文档：数据边界细节见《API 与数据使用边界》。

---

## 1. FinSight 是什么

FinSight 是一个**装在你自己电脑上的 A 股研究软件**。它的三个底线设计，决定了所有页面的使用方式：

| 设计 | 对你的直接影响 |
| --- | --- |
| **数据在本机** | 所有证据保存在本地文件与数据库里，软件只监听 127.0.0.1，别人访问不到 |
| **显式刷新** | 软件从不后台联网抓数据。页面上每一个"刷新 / 同步 / 开始研究"按钮，就是唯一会联网的入口；不点就不花钱、不请求 |
| **缺口可见** | 数据不足或字段缺失时显示 -- 并写明原因，**永远不用 0、估算或编造来补齐** |

它**只用于研究**：不提供交易、不自动下单、不保存你的持仓、不发送通知。

## 2. 快速上手（第一次使用）

1. **启动软件**：双击项目根目录的「启动FinSight.bat」。窗口会依次显示后端、前端就绪，然后自动打开浏览器（默认 http://127.0.0.1:5173）。黑窗口不要关，关了软件就停了。
2. **配置模型**：首次会停在"研究概览"，点"配置研究模型"进入设置页，按第 4 节配置一个自己的模型和同花顺 Key。
3. **确认第一个标的**：在"研究概览"页的**数据预览**里搜索一个股票（比如 600519），点候选列表里的"确认"。这一步把它的身份存进本机，之后所有页面才能使用它。
4. **取数据**：确认后回到研究工作台或公司体检，点"显式刷新"获取行情与财务证据。
5. **开始研究**：在工作台输入你的问题点"开始研究"，完成后到"研究资产库"管理报告。

## 3. 核心概念（先读懂这四个词）

### 3.1 确认标的

"确认标的"是使用一切数据的第一步：在数据预览里搜索并点"确认"后，软件把该证券的**身份**（代码、名称、类型、确认时间）存进本机。此后：

- 公司体检、同行比较、关注列表、基金研究、板块比较都**只认已确认的标的**；
- 未确认的标的会收到提示（见第 7 节提示语字典），确认一下即可解除；
- 确认过的标的会成为各页面"选择标的"按钮的数据源：点按钮弹出已确认标的表单，支持搜索与多选，确认后直接填入，不必再手输代码；
- 股票、指数、基金是不同类型，互相不能混用接口（股票代码发不到基金接口，反之亦然）。

### 3.2 显式刷新

页面上显示的都是**上一次刷新时保存的快照**。想让数据变新，必须手动点刷新按钮。没有"自动更新"，没有后台轮询——这是为了让你对每一次联网、每一笔费用都知情。

### 3.3 缺口可见

表格里的 --、图表上的空白、面板脚注里的"口径说明"，都是有意为之：缺失会告诉你**缺什么、为什么缺、影响什么**。看到 -- 不代表软件坏了，代表本地证据里确实没有这项数据。

### 3.4 证据与核验材料

研究任务产出的每个数字都有来源和口径。报告正文给人读；"核验材料（MD）"单独下载，内含结构化记录、脱敏后的上游原始响应与哈希，供你人工核对。

## 4. 设置页：模型与 API 配置

### 4.1 页面能做什么

管理你自己的模型服务和大数据库服务凭据（BYOK：自带 Key，软件不内置任何开发者的 Key）。

### 4.2 操作步骤

1. **配置模型**：选择官方预设（DeepSeek 等），只需填写 API Key；或使用"导入环境变量"读取 LLM_BASE_URL / LLM_MODEL / LLM_API_KEY 并加密保存。**导入或新增后必须手动点"激活"**，激活的模型才会参与研究。
2. **保存数据服务 Key**：分别为同花顺和博查保存自己的 Key。同花顺是唯一权威行情、财务与估值数据源。联网搜索只支持博查付费官方 API；本应用不使用爬虫获取任何网页内容。
3. **阅读交互指南**：首次使用顾问工作台前，请阅读 [FinSight 顾问与 Agent 交互指南](FinSight顾问与Agent交互指南.md)，了解标准提问、取消恢复、费用提示与隐私边界。
4. **能力测试**：每个能力都有独立测试按钮。**注意：保存 Key 不等于测试通过；涉及付费服务（博查）的真实测试可能计费，同花顺金融数据 API 免费开放（仅限流）**。测试结果会明确区分为：通过、未配置、无权限、额度限制、协议不兼容。
5. **模型试用区**：配置完成后可在试用区发一条消息验证模型确实可用。

### 4.3 注意事项

- 首次保存 Key 时，软件在本机初始化加密根密钥。**请私下备份项目根目录的 .env**——根密钥丢失后，已保存的密文无法恢复。
- 删除、禁用或更换凭据后，请求不会回退到任何环境变量或开发者 Key。
- 已发出的上游请求可能已产生费用，软件无法撤回。

## 5. 各页面使用说明

左侧导航从上到下依次是：研究概览、研究工作台、AI 聊天、公司体检、同行比较、关注与理由、研究资产库、板块研究、基金研究、市场复盘、全市场观察、模型与 API 配置。

### 5.1 研究概览（首页）

- **用途**：总览工作空间状态 + 数据预览（标的检索与确认）。
- **怎么用**：在数据预览的检索框输入代码或名称（如 600519 或 贵州茅台）→ 查看候选列表 → 点目标行右侧的"**确认**"。页面顶部显示当前已确认的标的与确认时间。
- **说明**：确认动作会把身份写入本机；检索本身会调用同花顺检索接口（需要 Key 已配置并测试通过）。

### 5.2 研究工作台

- **用途**：软件的主引擎——你提一个问题，它取证、计算、解释，并把缺口如实列出。
- **怎么用**：
  1. 在输入框用自然语言写研究问题（如"分析 600519 最近的盈利能力变化"）。
  2. 软件自动识别**研究范围**（公司概览、关注理由复核、指数强度、板块广度、市场脉搏、基金概览、基金比较、全市场广度、通用问答），并显示"当前范围：…；范围、来源和预算将在任务中保存"。
  3. 点"**开始研究**"。任务会显示模型、数据源和调用预算。
  4. 等待任务完成（状态从排队 → 运行 → 完成），阅读生成的报告：固定三段——**核心结论、分析依据、风险与待核验**。报告顶部可切换“图表版 / 文字版”；图表版优先展示后端已保存指标生成的看板、关系图或曲线，缺数仍会显示缺口说明。
  5. 在"继续追问"里围绕该报告继续提问；在补充区添加文字或资料后点"再分析"生成新版本。
- **状态标记**：partial（部分完成）、truncated（输出被截断）、unstructured（结构不完整）都**不代表完整正式结论**，请谨慎引用。

### 5.3 顾问工作台（AI 聊天）

- **用途**：围绕同一个研究问题多轮交流。顾问会先补齐目标、期限与风险约束，再使用已授权的只读数据、RSS、知识库与可选联网线索形成带情景、失效条件和跟踪哨的研究建议卡；完整建议会登记到台账供复盘。
- **怎么用**：
  1. 点“**新建会话**”或选择已有会话；在输入框写明标的、目标、期限、持仓或仓位上限、风险承受。
  2. 需要公开网页线索时，勾选“**本次允许联网搜索**”（使用已配置的博查付费服务，可能计费）；不勾选时不会发起该搜索。
  3. 选择“标准”或“深度”模式：标准模式默认启用，最多 4 次模型调用；深度模式才启用多分析师和辩论链。
  4. 点“**发送**”。页面先显示已提交或分析中，再实时显示公开阶段；完成后刷新消息与建议台账。
  4. 在途任务可点“取消”；取消或失败后可点“恢复”。恢复会按原问题重新运行，可能再次产生模型费用，不会自动执行。
- **免责**：建议卡是条件研究结论，不是交易指令；回答仅供研究参考，不构成收益承诺。详见 [FinSight 顾问与 Agent 交互指南](FinSight顾问与Agent交互指南.md)。

### 5.4 公司体检

- **用途**：单只股票的财务与行情体检，**只读本地证据**，不自动刷新、不调用模型。
- **怎么用**：
  1. 点输入框旁的"**选择标的**"，在已确认标的表单中点选一支（也可直接手输代码，如 601799.SH），再点"**读取本地资料**"。
  2. 阅读顶部 KPI 卡（最新收盘、区间涨跌、均线、均额、回撤、距高点）与行情工作台图表。
  3. 想要新数据：点"**刷新行情**"（默认拉取近 200 个自然日的日 K 与最新快照，这是全页唯一会联网的按钮）。
- **图表怎么读**：红色 = 涨、绿色 = 跌（A股习惯，全站一致）；K 线图可切换 30 / 90 / 160 日 / 全部区间；MA20 / MA60 由已保存收盘价计算；数据不足的地方显示 -- 并在表格备注里写原因。
- **常见提示**：见第 7 节"请先在数据预览中确认标的"。

### 5.5 同行比较

- **用途**：把 2–10 个**已确认**标的的财务与估值指标并排比较。
- **怎么用**：点"**从已确认标的选择（可多选）**"，在已确认标的表单中勾选 2–10 支后填入（也可手动输入代码，用逗号、中文逗号或空格分隔）→ 点"**构建本地比较表**"。表单填入会自动去重合并，最多 10 支。
- **规则**：只使用本地证据；当可比公司的报告期或会计口径不一致时，相关单元格会标出差异状态，**此时不排序**，只陈列事实。
- **常见提示**："标的 X 尚未确认，无法纳入比较"——先去数据预览确认 X，再回来重试。

### 5.6 关注与理由

- **用途**：维护你的自选清单和**研究理由**，并提供最近一次观察的行情快照。
- **怎么用**：
  1. 点"添加关注"：推荐先点"**从已确认标的选择**"，选中的标的会自动填入代码、名称与安全 ID；也可以手动填写（安全 ID 来自本机证据库，通常与代码一致）。
  2. 点"**更新观察（N）**"：软件会请求一次这些标的的最新行情快照与异动记录，并显示异动标签（接口返回的事实性原因）。
  3. 表格支持按涨跌幅、成交额排序；"日内区间"条显示当日最低—最新—最高的相对位置。
- **边界**：只保存研究标的和你确认的理由，**绝不保存持仓、不做后台监控、不发通知**；理由复核必须带报告证据或指标引用。

### 5.7 研究资产库

- **用途**：管理本地保存的全部研究报告；检索、对比、导出、删除都不调用外部 API。
- **怎么用**：
  - **打开 / 检索**：列表显示创建时间、版本号、标的、标签、覆盖程度与完整性标记。
  - **版本对比**：同一报告的多个版本可查看差异（补充资料"再分析"会产生新版本）。
  - **标签与笔记**：点"标签"维护本地组织标签。标签与笔记是你的注释，不是模型观点，改它们不会改报告结论。
  - **导出**：选择格式（Markdown / HTML / JSON / CSV）后点"下载"。HTML 可用系统浏览器打印成 PDF，图表会以静态快照嵌入，不依赖运行时脚本。默认导出的是**可读报告**；"**核验材料（MD）**"是单独下载项，含结构化记录与检索摘要，供人工核对。
  - **删除**：会先显示影响范围（附件、摘录、笔记、导出文件）；仍被投资理由引用的报告会**拒绝删除**，以保护历史可复核性。
- **版本固定**：报告正文、计算、证据和缺口随版本固定不变，不可改写。

### 5.8 板块研究

- **用途**：指数与行业板块的横向比较。
- **怎么用**：
  1. 选择指数类型（行业 / 概念 / 地域等），点"**显式刷新目录**"。
  2. 在下拉里选择 2–20 个指数（先选的会成为聚焦指数）。
  3. 点"**刷新选中指数与成分**"获取历史与成分；点"**比较所选行业**"生成比较面板。
  4. 阅读三个面板：**强度作战矩阵**（横轴 20 日强度、纵轴 5 日加速度，右上 = 强且加速，左下 = 弱且退潮）、**热力带**（5 / 20 / 60 日涨跌，红强绿弱）、**共同窗口分流**（同一段窗口的收益正负）。
  5. 下方还有聚焦指数走势与当前成分涨跌分布。
- **规则**：只比较共同交易日；没有共同窗口就不生成收益差；成分回看存在存活者偏差，页面会如实标注。

### 5.9 市场复盘

- **用途**：把某一天的盘后材料变成可读的市场结构图：涨跌停、连板梯队、热度排名、龙虎榜。
- **怎么用**：
  1. 选日期，点"**显式刷新盘后观察**"（默认范围：涨停、跌停、炸板、连板梯队、热度榜与 1 日龙虎榜）。
  2. 阅读四个面板：KPI 卡 → 涨跌停结构 → **连板梯队**（● = 次日封住，○ = 未封）→ 热度排名条 + 上榜原因树图。
  3. 历史复盘记录会保存；打开旧记录只读本地，不再联网。
- **规则**：不同统计窗口不会相加；历史日期没有异动解释时会明确显示不支持，不会把今天的说法移植过去。

### 5.10 全市场观察

- **用途**：基于本机全市场数据库（data/market/finsight_market.duckdb）做当日横截面观察。
- **怎么用**：
  1. 先看"数据状态"：没有数据时页面保持可读，不影响其他功能。
  2. 点"**显式同步近 10 日**"并在确认弹窗中同意：软件申请一次下载链接，把市场事实存进本机。链接不保存、不转发 Key；日 K 固定**未复权**口径。
  3. 选日期，点"**生成当日全市场看板**"：阅读涨跌分布（红涨绿跌灰平盘）与成交额前十排名。
- **规则**：涨跌家数按当日开盘价与收盘价比较；样本只含已下载的日 K，不代表实时行情。

### 5.11 基金研究

- **用途**：公募基金（场外 / 场内 / REITs）的基本资料、持仓、净值与比较。
- **怎么用**：
  1. 检索并**确认基金身份**（股票和指数不能发到基金接口）。
  2. 选择供应商类型（otc / exchange / reits）与要刷新的模块（基本资料、持仓与配置、净值与回撤、经理与分红、基金财务、资讯元数据、ETF 行情等）。
  3. 要读特定历史持仓：先"读取可选披露期"，再从上游已返回的报告期中选择；下一次"持仓与配置"刷新才会带上该期。
  4. 基金比较只读取本地已保存报告，且必须有共同期间。
- **口径**：持仓是披露事实而非实时持仓；单位净值与复权净值分列；无 IOPV 不计算实时折溢价；资讯只存标题、时间、来源和 URL。
### 5.12 新闻订阅

- **用途**：订阅媒体公开 RSS 端点形成本机新闻时间线，并可拉取同花顺官方资讯（基金资讯与个股异动解读）。
- **怎么用**：
  1. 在「订阅管理」添加媒体官方 RSS 地址并启用；点击单源右侧的「刷新」，或在「新闻时间线」点击「全部刷新」。
  2. 时间线可按来源与标的过滤；新闻条目只存标题、摘要、链接与时间，全文不入库。
  3. 「官方资讯」按钮（同花顺官方免费开放，仅限流）按已确认标的拉取基金资讯与异动解读，结果仅本次展示不落库。
  4. 轮询默认关闭；开启后仅自动抓取已订阅的免费公开端点。
- **口径**：新闻是线索（lead），关键数字与事实须经第二来源交叉验证；本产品不做任何网页抓取。

### 5.13 知识库

- **用途**：把本地文档（PDF/Markdown/TXT/CSV/TSV/XLSX）变成可检索、可引用的私有知识库。
- **怎么用**：
  1. 「选择文档 → 解析并入库」：解析与分块只在本机进行，重复上传同一文件会提示已存在。
  2. 「检索预览」输入检索词：命中显示摘录、文档名与原文定位（标题 / 第 N 页 / 第 X–Y 行）。
  3. 未启用嵌入时检索在本地关键词索引上完成，文档内容零外发；如需向量检索，在「模型与 API 配置」接入「Qwen 文本向量化」，此后摄取与检索会把相应分块文本发往嵌入服务。
  4. 文档内容或分块参数变化后可「重建索引」；删除文档会级联清除全部分块。
- **口径**：知识库命中是可核验佐证（corroborated），Agent 引用时必须注明文档名与定位；文件上限 25 MB，仅支持文本型 PDF（不做 OCR）。

### 5.14 策略实验

- **用途**：对已确认单标的运行固定规则的历史研究实验，不提供自动选股、实盘信号或自动交易。
- **怎么用**：填写确认过的代码、策略、开始/结束日期与单边成本，点击“运行”。结果会展示策略与基准净值、回撤、分段结果、交易次数及成本敏感性。
- **等级**：`样本不足`、`实验性` 和 `研究候选` 不是收益承诺；只有用户主动完成自然到期的影子验证，并达到前向校准门槛后，才能在策略 review 中明确确认为“已验证”。

### 5.15 顾问工作台

- **用途**：多轮对话的投资研究顾问——默认标准模式先澄清目标与期限、程序取证并匹配候选策略；深度模式才额外运行多分析师、辩论与风控审查。建议卡和策略依据会登记到影子验证台账。
- **怎么用**：
  1. 新建会话后直接提问（例：某标的现在能不能建仓、目标一个月内）；要素不齐时顾问会先反问，最多一次问 3 个。
  2. 建议卡包含：方向（倾向买入/继续持有/暂不买入/建议减仓/回避/证据不足暂不表态）、三情景概率（乐观/基准/悲观，合计 100%）、作废条件、跟踪哨与通俗决策理由（证据→排除→结论→反转条件）。
  3. 「查看本次分析过程」展开各阶段摘要；「本次允许联网搜索」默认关闭，勾选后本次对话才会调用已配置的付费搜索服务（仅返回标题与摘要）。
  4. 建议台账页签：每条完整建议自动登记；点「结算」或「结算已到期记录」按登记日后自然到期窗口的前复权收盘价核对。等待/拒答不混入方向命中率；经验概率不足时不会显示伪校准结论。
- **口径**：标准模式最多 4 次模型请求；深度模式最多 14 次（预算不足时优先省略辩论）。单个模型请求最多等待 25 秒，整条顾问链最多等待 75 秒，超时即停止且不自动重试，可在原会话继续提问；证据不足时顾问会明确说「证据不足，暂不表态」并列出还缺什么；没有候选策略实验时，服务器会将方向限制为等待或拒答。界面常驻「研究参考，不构成投资建议」。

## 8. 数据与安全边界

1. **唯一联网入口是页面上的显式按钮**：刷新、同步、开始研究、发送消息、能力测试。没有后台轮询、没有自动任务。
2. **所有外部请求使用你自己配置的 Key**，Key 加密保存在本机；导出文件、日志、报告中都不含 Key。
3. **数据在本机**：SQLite 证据库、DuckDB 市场仓库、报告与附件都在项目目录内。备份整机数据 = 备份项目目录（另请私下备份 .env 根密钥）。
4. **仅限本机使用**：应用只绑定 127.0.0.1。不要用隧道、反向代理或改绑 0.0.0.0 把它暴露到公网——它不是多用户服务。
5. **不提供交易**：没有下单、没有持仓管理、没有消息推送。

## 9. 常见问题（FAQ）

**Q：双击启动后浏览器没打开 / 页面打不开？**
黑窗口还在滚动就不算失败，等它显示前后端就绪。若提示端口被占用，按脚本提示关闭占用进程，或在项目 .env 里修改 FINSIGHT_PORT（后端，默认 8000）与 FINSIGHT_FRONTEND_PORT（前端，默认 5173）后重启。

**Q：页面上的图表是空白的？**
先看脚注和表格：如果表格也空，说明本地没有这项证据，点对应刷新按钮即可。图表面板自带"口径说明"和"出处"脚注，脚注在而图空 = 有数据但该维度缺口径。

**Q：为什么数据看起来是旧的？**
页面显示的是上次显式刷新的快照。点刷新按钮获取新数据；刷新前页面不会自己变。

**Q：确认标的 / 检索报错？**
多为同花顺 Key 未配置、未测试通过或额度用尽。去设置页看该能力卡片上的测试状态。

**Q：研究任务能撤销吗？**
不能撤回已发出的上游请求（可能已计费）。但刷新或断线后，研究页面会从同一任务事件序列继续读取，不会重复生成请求。

**Q：换电脑怎么迁移？**
复制整个项目目录（含数据与 .env）。在新机上首次保存 Key 前先确认根密钥已随目录迁移，否则旧密文无法解密。

**Q：这个软件会推荐我买什么吗？**
研究工作台与 AI 聊天可以给出**带条件的观点**，但每个结论都挂在证据与缺口说明上，且页面始终提示：仅供参考，不构成投资建议，不提供交易功能。
