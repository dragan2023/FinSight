# 01 — 首次准备与每日数据刷新

## 1. 摘要

- 优先级：最高
- 预计工作量：首次 30 分钟；每日 10—15 分钟
- 直接依赖：无
- 阶段目标：确认模型、行情、F10、RSS 和搜索确实被调用，并把当天盘后数据刷新到可研究状态。

## 2. 前置阅读

1. `README.md`
2. `docs/FinSight使用说明书.md`
3. `backend/app/advisor/graph.py`
4. `backend/app/api/routes/news.py`
5. `backend/app/api/routes/market_review.py`

## 3. 任务详情

### 3.1 首次设置检查

1. 打开“设置”页面，确认至少一个模型配置处于启用状态。
2. 分别执行模型聊天测试和工具调用测试；两项都成功才进入正式观察。
3. 确认同花顺数据能力已配置并可返回最新完整交易日的日 K、历史日 K、F10 财务与估值数据。
4. 确认付费搜索服务可用；搜索失败时当天建议必须标记为证据不完整，不得假装已联网。

### 3.2 新闻订阅页面刷新

1. 进入左侧菜单的“新闻订阅”页面。
2. 默认只有 3 个推荐 RSS 源是正常初始状态；它们是补充线索，不代表完整的证券新闻覆盖。
3. 对每个启用的 RSS 源逐一点击右侧“刷新”，或在页面下方点击“全部刷新”。
4. 在官方资讯区域点击“拉取官方资讯”。
5. 保持后台轮询关闭，避免产生不可控的自动记录。

### 3.3 盘后复盘刷新

1. 进入“盘后复盘”。
2. 确认日期是当天对应的最新完整交易日。
3. 点击“显式刷新盘后观察”。
4. 记录页面是否出现热度榜、涨停/异动和明确的数据时间。

### 3.4 全市场数据刷新

1. 进入“全市场”。
2. 点击“显式同步近 10 日”。
3. 选择最新完整交易日并点击“生成当日全市场看板”。
4. 确认市场广度、成交额排行等内容不是空白或旧日期。

## 4. 修改与数据范围

本阶段只通过页面触发已有接口，不修改源码。刷新结果进入 `data/db/finsight.db` 和 `data/market/finsight_market.duckdb`；模型与数据源配置保留在项目现有配置表中。

## 5. 禁止事项

1. 不在 15:00 收盘前使用尚未闭合的日线作为当天正式输入。
2. 不把搜索摘要当作已经核验的财务事实。
3. 不手工伪造刷新成功时间或直接改数据库。
4. 当任一关键数据源失败时，不继续生成“可买入”结论。

## 6. 验收标准

- [ ] 模型聊天测试成功。
- [ ] 模型工具调用测试成功。
- [ ] 最新完整交易日日 K、历史日 K、F10 可读取。
- [ ] “新闻订阅”中的 RSS 与官方资讯完成手动刷新，页面不再出现 `application/json` 错误。
- [ ] 盘后复盘显示正确交易日和非空结果。
- [ ] 全市场看板显示正确交易日和非空结果。
