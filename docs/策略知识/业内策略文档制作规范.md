# FinSight 业内策略文档制作规范

## 1. 交付物原则

本文件是 FinSight 内部整理和验收规范，不要求业内人士直接按本文件写作。对外只发送 `业内投资策略访谈问卷.md`，允许对方使用日常自然语言、案例和大致范围回答，也允许明确填写“不知道”或“主要靠经验判断”。

收到问卷后，FinSight 侧按 `问卷转策略文件工作规则.md` 整理出：

1. `策略名称_v版本_方法卡.md`：确定性、可复现的策略定义；未确认部分明确标为待确认。
2. `策略名称_v版本_验证报告.md`：已有证据、证据不足项与本机待验证方案；没有历史数据时不得虚构结果。
3. 可选 `策略名称_v版本_参数表.csv`：多资产或分市场参数。

整理后的规则必须回交原作者确认。AI 可以改写、分类和指出矛盾，不能自行补足仓位、阈值、时间或优先级。如果关键规则无法确认，该资料只能标为“假设/未审核”，不能作为已审核策略知识。

`业内策略方法卡模板.md` 和 `业内策略验证报告模板.md` 供 FinSight 内部转换使用，不再直接要求受访者填写。

## 2. 方法卡强制内容

### 2.1 身份与版本

策略唯一编号、中文名、版本、生效日期、作者、审核人、适用资产、市场、频率、目标持有期和版本变更记录。

### 2.2 经济或行为机制

说明策略试图捕捉什么现象、为什么可能存在、收益由什么风险或行为偏差补偿。必须列出至少一个反对解释，不能仅说“历史表现好”。

### 2.3 数据口径

逐项定义数据源、字段、频率、时区、复权方式、财务数据可得日、缺失值、停牌、涨跌停、退市、上市不足期和成分股历史口径。必须说明如何避免前视偏差、幸存者偏差和未来函数。

### 2.4 确定性规则

用公式或伪代码给出：特征、入场、退出、持有期、信号计算时点、最早成交时点、冲突信号优先级、空仓规则和重复信号处理。另一名工程师只凭文档应能得到相同信号。

### 2.5 组合与风控

说明仓位计算、单标的上限、行业上限、总仓位、波动率闸门、止损/退出、流动性门槛、最大回撤处理和极端行情暂停条件。

### 2.6 成本与可交易性

明确佣金、印花税、滑点、冲击成本、最小成交单位、T+1、停牌和涨跌停无法成交的处理。至少报告基准成本和更高成本压力测试。

### 2.7 适用与禁用条件

分别列出适用市场状态、禁用状态、数据失效条件、参数失效条件、策略失效判据和停用后的复核流程。条件必须可观察，避免“市场不好时不用”这类不可执行表达。

## 3. 验证报告强制内容

1. 样本起止日期、资产池形成规则和样本数量。
2. 训练、验证、测试或滚动前向划分；禁止只报告全样本最优结果。
3. 买入持有或合适基准，以及为何选择该基准。
4. 年化收益、累计收益、最大回撤、波动、Sharpe/Sortino、换手、交易数、胜率、盈亏比和最长回撤期。
5. 成本前后、参数扰动、起止日期扰动和子时期结果。
6. 按行业、规模、流动性和市场状态的分组结果。
7. 置信区间、Bootstrap 或其他不确定性描述；样本少时必须明确写“证据不足”。
8. 数据挖掘控制：尝试过多少参数/策略、最终版本为何被选中。
9. 最差时期、失败案例、异常成交假设和无法复现项。
10. 与方法卡逐条对应的实现版本、代码哈希或审计说明；不能只放净值曲线截图。

外部验证报告只能作为证据来源，不能替代 FinSight 本机历史门禁和未来影子验证。

## 4. 推荐写作格式

1. 首选 Markdown；标题使用 `#`、`##`、`###`，每个规则一个短段落，便于 RAG 分块定位。
2. 表格只放结构化参数和结果；公式同时给符号定义和自然语言解释。
3. 每个结论紧邻证据编号，例如 `[E-03]`，文末提供来源、页码、数据版本和访问日期。
4. 使用绝对日期和明确单位；不要写“近期”“低估”“高波动”等无阈值词。
5. 图表必须配数据口径和文字结论，不能让关键信息只存在图片中。
6. 不写“稳赚、稳定盈利、胜率很高、已经验证”等无边界宣传语。可写“在指定样本和假设下观察到”，并同时给局限。

## 5. FinSight 入库元数据

方法卡人工复核后设置：

| 字段 | 要求 |
|---|---|
| 知识角色 | `strategy` |
| 审核状态 | 首次为 `unreviewed`；完成逐条复核后才改 `approved` |
| 资产标签 | A 股使用 `a-share` |
| 期限标签 | `days_5`、`days_20`、`quarter` 或 `year` |
| 策略族 | 当前可用 `trend` 或 `reversal` |
| 市场状态 | 可选 `trend_up`、`trend_down`、`range`、`low_vol`、`high_vol` |
| 生效日 | 对应策略版本正式冻结日期 |

不同期限或不同规则版本应拆成不同文档，不能用一个“万能策略”文档覆盖所有场景。

## 6. 拒收条件

1. 无法确定信号时点或成交时点。
2. 未说明复权、成本、停牌和涨跌停处理。
3. 使用事后可得数据但没有披露。
4. 只有收益曲线、荐股案例或主观盘感，没有完整规则。
5. 参数来自最优回测但没有样本外或扰动检验。
6. 不披露失败条件、禁用状态或最差时期。
7. 文档声称已验证，但不能提供可审计验证附件。

满足格式只是“可进入审核”，不等于策略有效。
