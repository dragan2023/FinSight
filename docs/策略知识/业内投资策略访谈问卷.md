# 投资策略访谈问卷（自然语言版）

## 1. 填写说明

这不是考试，也不要求写公式、代码或专业报告。请像向一位熟悉投资但不了解你方法的朋友解释一样回答。

1. 可以使用日常语言、例子、大致范围或“通常、偶尔、很少”等表达。
2. 不确定的问题可以直接写“不确定”“没总结过”或“主要靠经验判断”。
3. 请描述你实际怎样做，而不是你认为标准答案应该怎样写。
4. 如果不同市场、不同股票或不同阶段做法不同，请分别说明。
5. 不需要承诺收益，也不需要证明策略有效；失败经历和不做的情形同样重要。
6. 预计填写时间 30–45 分钟。第 2–8 节为核心问题，第 9 节资料附件为可选项。
