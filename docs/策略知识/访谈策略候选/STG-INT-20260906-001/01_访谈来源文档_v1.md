# 基于经验的 A 股趋势判断访谈来源文档 v1

本文只保存问卷回答者的自然语言经验，未形成可执行规则，也未验证有效性。回答者允许全部内容进入 FinSight 私有知识库，但不允许把这些内容整理成规则草稿。因此，本文只能作为 `source + unreviewed` 来源资料检索，不得作为买卖信号、仓位指令或已审核策略使用。

填写人、填写日期和联系方式均未提供。

## 2. 方法概述

- 方法没有正式名称，主要依靠经验，使用约 3–5 年。（问卷 2.1–2.2）
- 回答者将其概括为“上升趋势之前买入，下降趋势之前卖出”。（问卷 2.3）
- 主要想解决找买入机会、控制风险和仓位的问题。（问卷 2.4）

## 3. 适用对象与检查频率

- 适用对象：A 股。（问卷 3.1）
- 不适用对象：基金、期货。（问卷 3.1）
- 持有时间没有固定期限，取决于条件。（问卷 3.2）
- 盘中多次检查，并在每天收盘后检查。（问卷 3.3）
- 回答者认为相对稳定的市场环境较适合，波动较大的环境最好不用。（问卷 3.4）

## 4. 关注与买入判断

- 开始关注一只股票时，主要看价格、趋势、公司盈利情况、成交量和行业前景。（问卷 4.1）
- 真正决定买入前，必须看到财报和近期走势。（问卷 4.2）
- 问卷把“有利好或利空”写在加分条件中，原回答未进一步解释。（问卷 4.2）
- 回答者称，经研判判断成功率低于 60% 时，即便看好也不买。（问卷 4.3）
- 信号出现后的行动时间视情况而定。（问卷 4.4）
- 多个信号相互矛盾时继续观察。（问卷 4.5）

## 5. 持有、加仓与退出

- 买入后观察价格、趋势以及是否出现利好或利空。（问卷 5.1）
- 价格走势偏离较大时可能加仓；走势在预料之中时不加仓。原回答未说明偏离方向。（问卷 5.2）
- 盈利或判断下跌较大时减仓或卖出。（问卷 5.3）
- 没有明显变化时等到下一次变化出现。（问卷 5.4）
- 遇到停牌、跌停或流动性不足时继续卖出，直到卖出为止。（问卷 5.5）

## 6. 仓位与风险

- 第一次买入最多使用约三分之一仓位。（问卷 6.1）
- 单只股票最多占总资金 90%，通常同时持有 1–2 只。（问卷 6.2）
- 回撤 20% 时重新检查甚至停止该方法。（问卷 6.3）
- 出现利空或趋势线变化、即将走弱时，立即停止买入或降低总仓位。（问卷 6.4）
- 回答者不考虑佣金、印花税、滑点和无法成交对做法的影响。（问卷 6.5）

## 7. 信息与判断依据

- 财经新闻：来源为炒股软件，每天打开软件查看，重要程度高。（问卷 7.1）
- 官方新闻：来自各种渠道，不定时查看，重要程度中。（问卷 7.1）
- 回答者认为走势与价格数据一般在一个月内都适用。（问卷 7.2）
- 价格区间与走向趋势主要依靠经验，暂时难以写成固定规则。（问卷 7.3）
- 最担心信息不够透明、用词模糊；平时会寻找相对的论据支持。（问卷 7.4）

## 8. 案例与失效看法

- 成功案例：在趋势即将翻转时买入，在下一周期即将反转前卖出；回答者认为多数靠运气成分。（问卷 8.1）
- 失败案例：看到趋势线不错，但忘记分红时间节点，随后股价大幅下跌。（问卷 8.2）
- 边界案例：曾因忙于其他事情而最终没有行动。（问卷 8.3）
- 回答者认为成功率低于 50% 时，方法可能已经失效。（问卷 8.4）
- 过去调整：大体逻辑不变，微调买入点，且认为关键节点仍有进步空间。（问卷 8.5）
