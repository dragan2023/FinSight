# FinSight 顾问与 Agent 交互指南

## 1. 开始前

顾问用于本地研究辅助，不构成投资建议，也不承诺收益。首次使用请在“模型与 API 配置”中保存并激活自己的模型；需要联网线索时，另行配置博查并在本次提问时勾选联网搜索。

## 2. 推荐提问方式

一次写清以下信息，顾问可直接进入分析而不重复澄清：标的代码、目标、期限、当前持仓或仓位上限、风险承受或最大回撤。

示例：“请研究 600519.SH；目标是学习研究；期限三个月；当前无持仓，最大仓位不超过 10%，最大可接受回撤 5%，风险偏好平衡。数据不足时请列出缺口。”

## 3. 遇到澄清问题时

若信息不足，顾问最多提出三项缺失要素。直接在同一会话补充即可，例如：“期限改为一个季度；我已持有 5%；最大回撤仍为 5%。”不要把未核实的传闻写成事实；可明确标为“我的假设”。

## 4. 标准与深度任务、取消与恢复

默认“标准”模式在要素齐全时用程序取证与一次综合生成建议卡，最多 4 次模型调用；它会优先匹配本地候选策略实验。选择“深度”模式才会运行多分析师与辩论链，仍受单次预算限制。发送后会先显示“已提交”或“分析中”，页面会通过实时进度流显示公开阶段，断线重连不会自动重放模型调用。可点击“取消”停止在途请求；取消或失败后，点击“恢复”才会再次执行，系统不会自动重放可能计费的模型调用。恢复会按原问题重新运行，因此仍可能产生模型费用。若在任务进行中关闭软件，任务不会保留或自动续跑，请新建一次任务。

## 5. 联网与费用

“本次允许联网搜索”只在本次任务生效，使用已配置的博查服务并只取标题、摘要和链接。模型调用和联网搜索都可能计费；只在确认账户、问题范围和数据最小化后启用。未勾选联网搜索时，新闻仅使用本地已有材料、RSS 或知识库线索。

## 6. 理解输出

- 建议卡包含情景、概率、失效条件、跟踪哨和免责提示；它是条件研究结论，不是交易指令。
- “证据不足，暂不表态”表示可用证据不能支持方向判断，应先补充资料或刷新被授权的数据。
- “缺口”表示未取得、无权限或口径无法确认的数据，不能视为零。
- “超时”表示本次深度任务已停止；可在检查范围后显式恢复，不会后台自动重试。
- RSS、搜索和网页摘要属于线索，不能单独替代同花顺的行情、财务或估值事实。
- “候选策略实验”是可复现历史研究，不等于未来有效；没有候选实验时，服务器只会给出等待或拒答结论。置信度由证据、策略等级和前向校准状态决定，模型不能自行抬高。

## 7. 信息与隐私边界

只提供完成研究所需的信息，避免发送身份证号、账户余额、交易密码或完整交易流水。模型请求会发送本次问题和必要研究材料；密钥不会显示在页面、日志或建议卡中。上传的本地资料不会自动外发或自动再分析。

## 8. 常见误区

1. 只问“能买吗”：缺少期限和风险约束，通常会触发澄清。
2. 把搜索摘要当财务事实：应以同花顺数据或可定位原文核验。
3. 取消后等待自动继续：取消不会自动恢复，必须由你点击“恢复”。
4. 将建议卡当作收益保证：任何方向、概率和仓位讨论都仅供研究与教育参考。
